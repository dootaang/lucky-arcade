# SPEC-A24 — 테메로세 슬롯 777 수직 시제품

> 상태: v2.1 구현 계약 (2026-07-27). 선행: A17 카지노 초상 감사 · A23 공용 판돈 영수증.

## 1. 목적

테메로세 네 시리즈 카드에 실제로 들어 있던 인물·감정 스프라이트를 슬롯 릴 심볼로 사용한다. 슬롯은 테메로세 카지노의
첫 기계 구역이며, 무료 포인트 발행원이 아니다. 포인트가 없으면 도둑잡기에서 먼저 벌어야 한다.

규칙과 결과는 `cabinets/slot-machine`의 순수 코어가 소유하고 릴 애니메이션은 이미 확정된 3×3 결과를
표현할 뿐이다. 릴 정지 시점이나 프레임 속도가 배당을 바꾸지 않는다.

## 2. 심볼 계약

- 팩: `0.2.0`. 기존 `temerosa-margin` 파생본을 참조하므로 이미지를 중복 배포하지 않는다.
- 심볼: 바치칼을 제외한 인물 38명. Overture·Root2·Bestiaization·Finale의 감정 변형 268종을 표현 재고로 쓴다.
- **인물이 판정 심볼이고 표정·시대 외형은 표현 변형이다.** 같은 회전에서 같은 인물은 반드시 같은 그림으로 보인다.
- 38명 모두 `weight: 1`이다. 정본 근거가 없는 희귀도나 등급을 만들지 않는다.
- 매 회전마다 38명 중 서로 다른 6명을 시드로 고르고, 3×3 칸을 그 6명에서 동등 확률로 뽑는다.
- 표현 변형은 시드와 인물 ID로 결정하며, 여러 시리즈 외형이 있는 인물은 먼저 시리즈를 균등 선택한 뒤 표정을 고른다.
- 진입 시 전량 선로드하지 않는다. 준비 화면 9장과 회전에서 실제 쓰는 6장의 `md`만 요청한다.
- 이름은 접근성 라벨에 원본 표시명을 보존하지만 화면의 당첨 위계로 사용하지 않는다.
- `postImplementationReview: pending` 에셋은 오너의 선구현 승인에 따라 화면 확인 뒤 교체할 수 있다.

## 3. 판정과 배당

당첨선은 다섯 개다.

1. 위 가로
2. 가운데 가로
3. 아래 가로
4. 좌상단→우하단 대각선
5. 좌하단→우상단 대각선

한 선의 세 칸이 같은 심볼이면 판돈의 `6배`를 지급한다. 여러 선이 맞으면 배수를 합산한다. 당첨선이 없으면
지급액은 0이다. 지급액은 예약 후 돌려받는 **총 credit**이며 원금도 별도로 더하지 않는다.

- 판돈: 10 · 50 · 200 P
- 최대 배수: 30배
- 배당 계약: `temerosa-slot-paytable/0.2`
- 심볼 풀을 6종으로 제한한 5라인의 이론상 평균 총 지급률은 약 83.3%다.

## 4. 시간축과 저장

```text
ready/complete
  → A23 판돈 예약
  → spin: 시드·3×3 결과·당첨선 확정
  → 실제 세로 릴 트랙 3개를 서로 다른 시점에 정지
  → finish
  → A23 한 번 정산
```

- 예약이 성공하기 전에는 코어의 `spin`을 기록하지 않는다.
- `choiceKey`에 `spin:<seed>`를 남겨 예약 직후 탭이 닫혀도 같은 결과를 복원한다.
- WAL과 스냅숏은 기존 `recoverSession` 계약을 사용한다.
- 새로고침·뒤로가기는 환불 사유가 아니다. 예약된 회전을 복구해 완료한다.
- 정산 실패 시 완료 결과를 보존하고 다음 진입에서 같은 영수증을 멱등 정산한다.
- `0.1` 미정산 영수증은 새 심볼 결과로 재해석하지 않고 전액 시스템 환불한다.

## 5. 화면

- 데스크톱은 기계와 조작 패널을 2열로, 모바일은 1열로 배치한다.
- 심볼 이름·가상 레어도·정본에 없는 설명을 이미지 위에 붙이지 않는다.
- `BET`은 10→50→200 P를 순환하고 `MAX BET`은 현재 잔액으로 가능한 최대 판돈을 고른다.
- 판돈 선택은 예약이 아니다. 별도의 물리형 레버를 당긴 순간에만 A23 판돈을 예약하고 회전을 시작한다.
- 각 릴은 지나가는 심볼 트랙을 실제로 이동하고 2.40초·3.15초·3.90초에 차례로 멈춘다.
- 첫 두 릴이 선언된 당첨선에서 같은 인물을 만들면 리치로 판정해 마지막 릴을 4.60초까지 끈다. 리치는 표현 시간만 바꾸며 결과·배당·난수 소비를 바꾸지 않는다.
- 가속→정속→감속 뒤 11px 오버슈트와 기계 반동으로 정렬한다. 모든 릴이 멈춘 뒤 당첨선을 순서대로 그리고, 감정 컷인, 정산, 포인트 카운트업 순으로 표시한다.
- 일시정지와 백그라운드 전환은 타이머가 아니라 세 릴의 `Animation` 객체를 함께 멈춘다.
- 감축 모션에서는 연속 이동 없이 즉시 결과를 표시한다.
- 현재 잔액보다 큰 판돈은 `BET` 순환에서 제외하며 `MAX BET`도 이를 넘지 않는다.
- 모바일 레버는 기계 아래에 두고, 데스크톱 레버는 기계 오른쪽에 둔다. 둘 다 실제 `button`이며 키보드와 스크린리더로 조작할 수 있다.

## 6. 완료 관문

1. 같은 팩·시드는 3×3 결과와 `resultHash`가 같다.
2. 10,000시드에서 당첨선과 배수가 선언된 다섯 선에서만 나온다.
3. 판돈 예약·정산은 지갑과 A23 영수증에 정확히 한 번 반영된다.
4. 예약과 상태 저장 사이 종료를 같은 시드로 복구한다.
5. 감축 모션·모바일·새로고침 E2E를 통과한다.
6. A17 팩 감사, 경계, 타입, 전체 단위, 초기 JS 200KiB 예산을 통과한다.

## 7. 비범위

- 잭팟 누적 풀, 무료 스핀, 와일드·스캐터, 보너스 게임
- 심볼별 차등 희귀도와 배당
- 유료 포인트 구매, 서버 전송, 외부 환전
- 파칭코·플링코 물리
- 릴별 `STOP` 버튼과 사운드·음량 설정. 결과를 바꾸지 않는 후속 표현 기능으로 남긴다.
