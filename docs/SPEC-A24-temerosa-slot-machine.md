# SPEC-A24 — 테메로세 슬롯 777 수직 시제품

> 상태: v1.0 구현 계약 (2026-07-26). 선행: A17 슬롯 축약팩 · A23 공용 판돈 영수증.

## 1. 목적

테메로세 카드에 실제로 들어 있던 유물·괴물 이미지를 슬롯 릴 심볼로 사용한다. 슬롯은 테메로세 카지노의
첫 기계 구역이며, 무료 포인트 발행원이 아니다. 포인트가 없으면 도둑잡기에서 먼저 벌어야 한다.

규칙과 결과는 `cabinets/slot-machine`의 순수 코어가 소유하고 CSS 애니메이션은 이미 확정된 3×3 결과를
표현할 뿐이다. 릴 정지 시점이나 프레임 속도가 배당을 바꾸지 않는다.

## 2. 심볼 계약

- 팩: `temerosa-casino-slots/0.1.0`
- 심볼: 감사된 16종, 1x/2x WebP 총 213,516바이트
- 첫 버전은 16종 모두 `weight: 1`이다. 정본 근거가 없는 희귀도나 등급을 만들지 않는다.
- 매 회전마다 16종 중 6종을 시드로 고르고, 3×3 칸을 그 6종에서 동등 확률로 뽑는다.
- 이름은 접근성 라벨에 원본 표시명을 보존하지만 화면의 당첨 위계로 사용하지 않는다.
- `postImplementationReview: pending` 에셋은 오너의 선구현 승인에 따라 화면 확인 뒤 교체할 수 있다.

## 3. 판정과 배당

당첨선은 다섯 개다.

1. 위 가로
2. 가운데 가로
3. 아래 가로
4. 좌상단→우하단 대각선
5. 좌하단→우상단 대각선

한 선의 세 칸이 같은 심볼이면 판돈의 `6배`를 지급한다. 여러 선이 맞으면 배수를 합산한다. 당첨선이 없으면
지급액은 0이다. 지급액은 예약 후 돌려받는 **총 credit**이며 원금도 별도로 더하지 않는다.

- 판돈: 10 · 50 · 200 P
- 최대 배수: 30배
- 배당 계약: `temerosa-slot-paytable/0.1`
- 심볼 풀을 6종으로 제한한 5라인의 이론상 평균 총 지급률은 약 83.3%다.

## 4. 시간축과 저장

```text
ready/complete
  → A23 판돈 예약
  → spin: 시드·3×3 결과·당첨선 확정
  → CSS 릴 연출
  → finish
  → A23 한 번 정산
```

- 예약이 성공하기 전에는 코어의 `spin`을 기록하지 않는다.
- `choiceKey`에 `spin:<seed>`를 남겨 예약 직후 탭이 닫혀도 같은 결과를 복원한다.
- WAL과 스냅숏은 기존 `recoverSession` 계약을 사용한다.
- 새로고침·뒤로가기는 환불 사유가 아니다. 예약된 회전을 복구해 완료한다.
- 정산 실패 시 완료 결과를 보존하고 다음 진입에서 같은 영수증을 멱등 정산한다.

## 5. 화면

- 데스크톱은 기계와 조작 패널을 2열로, 모바일은 1열로 배치한다.
- 심볼 이름·가상 레어도·정본에 없는 설명을 이미지 위에 붙이지 않는다.
- 감축 모션에서는 릴 흔들림·블러 없이 즉시 결과를 표시한다.
- 백그라운드에서는 회전 완료 타이머를 멈추고 돌아온 뒤 이어간다.
- 현재 잔액보다 큰 판돈 버튼은 선택할 수 없다.

## 6. 완료 관문

1. 같은 팩·시드는 3×3 결과와 `resultHash`가 같다.
2. 10,000시드에서 당첨선과 배수가 선언된 다섯 선에서만 나온다.
3. 판돈 예약·정산은 지갑과 A23 영수증에 정확히 한 번 반영된다.
4. 예약과 상태 저장 사이 종료를 같은 시드로 복구한다.
5. 감축 모션·모바일·새로고침 E2E를 통과한다.
6. A17 팩 감사, 경계, 타입, 전체 단위, 초기 JS 200KiB 예산을 통과한다.
