# 트럼프 카드게임 확장 후보 — 2026-07-28 오너 승인

> 상태: 아이디어 승인 기록. 구현 순서와 세부 계약은 각 게임 착수 전에 별도 명세로 확정한다.

## 1. 포커 용어

`로열 스트레이트 플러시`는 같은 무늬의 `10-J-Q-K-A`로 이루어진 최고 등급의 스트레이트 플러시다.
영어권의 일반적인 이름은 `Royal Flush`이며, 국내에서는 `로열 스트레이트 플러시`라고도 부른다.

현재 카지노 로드맵에는 텍사스 홀덤이 있지만 대형 후순위 게임이라, 포커 족보를 직접 만들고 배우는
경험이 사실상 비어 있다. 이를 작은 정통 포커부터 채운다.

## 2. 우선 추가할 포커 계열

1. **파이브 카드 드로 포커**
   - 다섯 장을 받고 원하는 카드를 교환한 뒤 족보를 겨룬다.
   - 원페어부터 로열 플러시까지 공용 족보 판정을 전부 사용한다.
   - 상대의 교환 장수가 공개 정보가 되므로 NPC 표정·블러핑과 결합하기 좋다.
   - 텍사스 홀덤보다 구현과 학습 부담이 작아 정통 포커의 첫 공개판으로 삼는다.
2. **비디오 포커**
   - 다섯 장 중 유지할 카드를 선택하고 나머지를 한 번 교환해 배당을 받는다.
   - NPC 대전은 없지만 슬롯의 램프·레버·기계 연출을 재사용할 수 있는 짧은 포인트 소비처다.
3. **쓰리 카드 포커**
   - 세 장으로 딜러와 빠르게 승부한다. 짧은 카지노 테이블 게임 후보로 둔다.
4. **세븐 카드 스터드**
   - 공개 카드가 많아 카드 추적과 NPC 반응을 함께 활용할 수 있으나 다중 베팅 때문에 후순위다.
5. **오마하 홀덤**
   - 텍사스 홀덤 완성 뒤 같은 기반을 재사용하는 확장 규칙으로 둔다.

공용 판정기의 재사용 정도를 기준으로 각각 승격한다.

파이브 카드 드로 포커를 홀덤보다 먼저 두는 것이 이번 결정의 핵심이다. 작은 구현으로 정통 포커 족보를
보여 주면서 카드 교환, NPC 표정, 블러핑이라는 테메로세 카지노의 자산을 함께 사용한다.
