> 상태: 스토리 정본·감정 항해 게임플레이 정본 반영 v4.0 구현 계약.
> 콘텐츠 원본: `C:\freetalk\테메로세\Temerosa_Finale.charx` 외 테메로세 시리즈 3종.

- 유일 스토리 정본: [`게임 스토리 개요 정본.md`](./게임%20스토리%20개요%20정본.md)

## 1. 플레이어가 실제로 경험할 것

플레이어는 무너진 피쿼드 폐허에서 물자를 찾던 미등록 생존자다. 플레이어가 직접 고장 난 계약 단말기를 깨우자 박니은이
비정상적인 옛 플루토 신호를 포착한다. 알제는 현재 생존자를 과거와 함께 폐기하려는 단말기를 통과시키기 위해 플레이어를
`피쿼드 임시 항해사`로 등록한다. 플레이어는 페일·카노·네모/바치칼 가운데 두 명과 과거를 현실에 덮어쓰는 트레인헤드를
추적한다. 첫 사망 또는 보스전 종료 뒤에야 워어즈와 여백을 발견하고, 무너진 항로의 선택을 기억한 채 돌아와 `항해사`라는
직책을 획득한다.

현재의 니은은 세계 끝에서 사상 지평을 유지해 대멸종을 막고 있으므로 현장 동료처럼 이동하지 않는다. 첫 연결에서는 플레이어를
우연히 폐허 신호에 걸린 생존자로만 안다. 워어즈와 반복의 흔적은 플레이어가 여백에서 돌아온 뒤에야 확인한다.

이 시제품의 목적은 다음 한 문장을 검증하는 것이다.

> 플레이어가 “내가 강해서가 아니라 고르고 기억하기 때문에 이 사람들이 나를 필요로 한다”고 느끼고,
> 다른 동료 조합의 반응을 보기 위해 다시 출발하는가.

## 2. 장르와 표현

- 장르: 비주얼노벨 화면 × 노드 탐사 × 기억 카드 턴제인 감정 항해 JRPG.
- 한 회차 목표: D1은 20~40분. 언제든 중단 저장하고 돌아올 수 있다.
- 메뉴·덱·대화 기록·선택지: React.
- 전투·배경 전환·컷인·파티클·보스 왜곡: Phaser 4 지연 로딩.
- 판정·시드·대사 선택·결과 해시: DOM 없는 순수 TypeScript 코어.
- 런타임 LLM 호출: 없음. 모든 발화는 검수된 대사집에서 선택한다.
- 원본 일러스트는 도트 이동 스프라이트로 가장하지 않는다. 인물 컷인, 카드, 반신 초상, 배경, 괴물 전면 일러스트로 사용한다.

## 3. 첫 수직 시제품 범위

### 포함

- 허브 2개: 피쿼드 폐허 임시 거점, 첫 사망/보스 종료 뒤 열리는 여백.
- 플레이어 역할: 미등록 생존자 → 피쿼드 임시 항해사 → 여백을 발견한 항해사.
- 지역 1개: 피쿼드 폐허와 과거 메트로 정거장을 잇는 7노드 경로.
- 동료 3명 중 2명 선택: 페일, 카노, 네모/바치칼.
- 동료별 동행 조건·거부권과 조합별 전용 계약 카드 1장. 알제는 항로 승인만 하며 전투 수행·거부권은 동료에게 있다.
- 임무 주도자: 박니은. 현지 연결자: 알제. 부활 담당: 워어즈.
- 과거 기록 인물: 라일라/리엘.
- 일반 적 3종과 환경 위협: 토끼벌, 눈눈늑대, 신경나무, 과거 회귀 충돌.
- 보스 1종: 트레인헤드.
- 고정 행동 4개(기술·관찰·기다림·공명) + 기억 카드 영역. 핵심 기억은 고정하고 전술 기억만 덱으로 순환한다.
- 동료별 전용 전술 기억 카드. 정확한 기본 덱 수는 플레이 시제품에서 확정한다.
- 수치: 생명력, 인간성, 짐승성. 배고픔·갈증은 D1에서는 사건 조건으로만 사용하고 상시 감소시키지 않는다.
- 사건 3개, 휴식 1개, 전투 3개, 보스 1개.
- 사망·부활·중단 저장·재개.
- 항해사 선택 태도 4종과 첫 행동 회수.
- 핵심 7인 대사 성경·관계 규칙과 첫 회차 전체 대본 v3.

### 제외

- 세 지역 전체, 10개 세력 전체, 30인 플레이어블화.
- 실시간 자유 이동, 타일맵, 포켓몬식 포획.
- 음성 더빙, BGM. D1은 합성 효과음과 화면 연출만 허용한다.
- 생성형 대사, 사용자 자유입력에 대한 의미 응답.
- 공용 재화, 과금, 서버 점수판.
- 성인 에셋과 성적 설정. 콘텐츠 컴파일 단계에서 허용 목록 밖의 항목을 제외한다.

## 4. 첫 회차 구조

| 순서 | 장면 | 플레이 |
|---|---|---|
| 0 | 죽은 단말기 | 폐허를 수색하던 플레이어의 첫 행동, 박니은 원격 연결 |
| 1 | 마지막 인사부 | 알제 조우, 임시 항해사 등록, 플레이어 역할 획득 |
| 2 | 함께 갈 두 사람 | 조건·거부권을 확인하고 페일·카노·네모/바치칼 중 둘 편성 |
| 3 | 살아 있는 계약서 | 항해사 카드와 동료 카드, 인간성·짐승성 학습 |
| 4 | 세 가지 처리 규정 | 사람/이름/물자 중 하나 완전 회수·하나 손상·하나 상실 |
| 5 | 리엘의 사무실 | Bestiaization 시대 복원, 라일라·니은·알제의 과거 기록 |
| 6 | 도착하지 못한 승객 | 니은 통신 없이 현장 조합이 `집·살다·기다리다` 단서 수집 |
| 7 | 트레인헤드 | 직접 피해 0, 키워드로 목적지 규칙 해제 |
| 8 | 여백 발견 | 사망/무사망별 워어즈 첫 조우, 첫 사망이면 잔향·죽은 항로 카드·보스 변형 개방 |
| 9 | 항해사의 귀환 | 사망 여부와 무관한 기억 검증, 동료들의 첫 호칭, 알제의 행정 확인 |
| 10 | 다음 방위 | 페일 동행은 익숙함, 카노+네모는 구조 신호의 이름으로 감정의 바다 개방 |

경로는 D1에서 고정 뼈대를 사용하되 전투·사건의 세부 순서와 대사는 시드로 달라진다. 첫 회차는 학습을 위해
항상 위 순서를 보장하고, 두 번째부터 두 노드의 위치와 적 구성을 바꾼다.

## 5. 대사가 장식이 아니게 하는 규칙

1. **정보**: 위험, 보스 규칙, 자원 변화 중 최소 하나를 말 또는 표정으로 알려준다.
2. **관계**: 같은 사건도 동료 조합에 따라 의견과 후속 효과가 달라진다.
3. **기억**: 사망 횟수, 같은 보스 연속 패배, 이전 선택, 동료 동행 횟수를 기억한다.
4. **대가**: 중요한 대화 선택은 인간성·짐승성·관계·카드 중 최소 하나를 바꾼다.
5. **침묵**: 모든 행동에 말하지 않는다. 긴장 장면에서는 의도적으로 무음 구간을 둔다.
6. **재현**: 같은 게임 버전·시드·입력 기록이면 같은 발화가 선택된다.
7. **주인공성**: 항해사의 선택은 직접 최강 공격이 아니라 경로·대상·후퇴·회수를 바꾼다.
8. **획득**: 신뢰와 직책은 설명으로 선지급하지 않고 첫 회차의 행동으로 얻는다.
9. **병목**: 회귀 기록 고정, 상충 실행안 확정, 죽은 항로 약속의 처리는 항해사만 수행한다.
10. **사전 고지**: 동행 조건·거부권·완전 회수/손상/상실·전용 카드의 위험은 선택 전에 표시한다.
11. **표정 정보**: 표정은 연기·전투 예고·말과 감정의 불일치·시간 반복의 증거로 사용한다.
12. **오독 분기**: 표정을 다르게 해석해도 게임오버·호감도 벌점으로 처벌하지 않고 다른 정보와 결과로 이어진다.
13. **접근성**: 핵심 관찰은 이미지 외에 `시선을 출구로 돌렸다` 같은 비해석적 관찰 문장을 제공한다.

### 주요 선택의 대가 계약

| 선택군 | 선택 전 공개 정보 | 반드시 달라지는 상태 | 나중에 자동 복구할 수 없는 것 |
|---|---|---|---|
| 첫 행동 4종 | 보존 자원 1개·상실 자원 1개 | 전력·구조 신호·기록과 장면 5/9 회수 대사 | 상실한 원본 기록 또는 구조 음성 |
| 동료 편성 | 조건·거부권·전용 카드 위험 | 동료 둘, 조건 준수 상태, 조합 계약 | 비동행 조합 전용 카드·재주행 정보 |
| 장면 4 보급함 | 하나 완전·하나 손상·하나 상실 | 단서 상세도·보상·보스 이해·귀환 평가 | 상실 상자 전체와 손상 상자의 세부 정보 |
| 트레인헤드 마지막 목적지 | 보상·잔향·알제 반응 | 현재 기록과 귀환 대사 | 선택하지 않은 목적지의 이번 회차 결과 |
| 현재 기록 고정 | 남는 정보·잃는 정보·관계 반응 | 정본 항로 기록 1개, 죽은 항로 기록 1개 | 둘을 동시에 현재 정본으로 만드는 것 |

장면 4의 판정표는 대본 v3 개정판 §7을 정본으로 삼는다. 어떤 선택에서도 세 상자를 모두 확인하거나, 상실한 상자를 같은
회차의 후속 대사로 되돌려 주지 않는다.

### 조합 효과 계약

| 조합 | 전용 카드 | 정보 축 | 위험·대가 | 다음 항로 동력 |
|---|---|---|---|---|
| 페일+카노 | `응답하는 사슬` | 구조 신호·승객 호흡 | 오지정 시 카노 방어 기회 소모 | 페일의 익숙함 |
| 페일+네모 | `이름의 닻` | 삭제 전후 이름 기록 | 고정한 이름을 보상 카드로 가져갈 수 없음 | 페일의 익숙함 |
| 카노+네모 | `종료 승인` | 생환 환산표·명령 시각 | 보스 공격 하나 제거 대신 감정 기록 하나 상실 | 구조 신호의 이름 |

각 조합은 전용 카드·장면 4 결과·보스 위험·귀환 정보 중 최소 세 항목이 달라야 한다. 대사만 다르고 판정 결과가 같으면
조합 구현 실패다.

## 6. 대사 코어 계약

```ts
type DialogueIntent =
  | "scene" | "exploration" | "combat-start" | "skill" | "hurt"
  | "low-humanity" | "high-beasthood" | "victory" | "defeat"
  | "revive" | "banter" | "choice" | "boss-hint";

type DialogueCondition = {
  sceneIds?: string[];
  speakerIds?: string[];
  companionIds?: string[];
  enemyIds?: string[];
  minDeaths?: number;
  maxDeaths?: number;
  minHumanity?: number;
  maxHumanity?: number;
  minBeasthood?: number;
  requiredFlags?: string[];
  forbiddenFlags?: string[];
  playerApproaches?: ("reach" | "observe" | "reckon" | "ask")[];
  navigatorStage?: "unregistered" | "provisional" | "navigator";
};

type DialogueLine = {
  id: string;
  speakerId: string;
  intent: DialogueIntent;
  text: string;
  portrait: string;
  priority: 0 | 1 | 2 | 3;
  cooldown: number;
  oncePerRun?: boolean;
  onceEver?: boolean;
  condition: DialogueCondition;
  effects?: GameEffect[];
};

type DialogueBeat = {
  lineId: string;
  appearanceSet: string;
  surfaceGoal?: string;
  visibleEmotion?: string;
  internalEmotion?: string;
  concealedFact?: string;
  startExpressionId: string;
  midExpressionId?: string;
  endExpressionId?: string;
  observationFocus?: "eyes" | "mouth" | "hands" | "body" | "frame";
  observationFact?: string;
  dramaticCue?: string;
  criticality: "general" | "transition" | "required";
};

type DialogueCue = {
  intent: DialogueIntent;
  sceneId: string;
  actorId?: string;
  targetId?: string;
  enemyId?: string;
  priority: 0 | 1 | 2 | 3;
};

type CompanionPact = {
  companionId: "pale" | "kano" | "nemo";
  conditionId: string;
  refusalRuleId: string;
  accepted: boolean;
  breached: boolean;
};

type SalvageState = "complete" | "damaged" | "lost";

type NavigatorDecision = {
  id: string;
  sceneId: string;
  offeredPlanIds: [string, string];
  selectedPlanId: string;
  anchoredRecordId: string;
  deadRouteRecordId?: string;
};

type EchoState = {
  deaths: number;
  deadRouteCardIds: string[];
  bossVariantIds: string[];
  rememberedPromiseIds: string[];
};

type BondStage = "unfamiliar" | "recognized" | "trusted" | "bonded";
type PressureStage = "stable" | "cracked" | "near-collapse";

type CharacterEmotionState = {
  characterId: string;
  bond: BondStage;
  pressure: PressureStage;
};

type CoreMemory = {
  id: string;
  kind: "name" | "promise" | "place" | "emotion" | "silence" | "sequence";
  pinned: true;
};

type TacticalMemory = {
  id: string;
  drawWeight: number;
  exhausts: boolean;
};
```

- 전투 코어는 문자열을 직접 선택하지 않고 `DialogueCue`만 발생시킨다.
- 대사 감독은 현재 `RunState`, 영구 `StoryMemory`, 최근 발화 기록을 받아 후보를 걸러낸다.
- 후보 정렬은 우선순위 → 미사용 가중치 → 결정론 난수 순이다.
- 발화 효과는 별도 `GameEffect`로 판정한다. UI가 대사를 표시했다고 직접 상태를 변경하지 않는다.
- 저장에는 대사 ID, 선택지 ID, 발생 턴, 결과 효과만 기록한다. 전체 텍스트는 버전 콘텐츠에서 복원한다.
- `StoryMemory`는 첫 행동의 보존·상실, 동료 계약 수락·위반, 장면 4의 세 `SalvageState`, 실제 입력 기록, 현재 기록과 죽은
  항로 기록을 분리해 저장한다.
- 기억 검증의 정답은 대사 텍스트에서 추론하지 않고 저장된 선택지 ID로 판정한다. 무사망 경로에서도 같은 검증 계약을 사용한다.
- 첫 사망이 발생한 틱에 `EchoState`의 카드 1장과 보스 변형 1개를 함께 기록한다. UI 노출 누락이 있어도 판정 상태는 남아야 한다.
- 알제의 정식 전환 효과는 선택한 두 동료의 첫 `navigator` 호칭 큐가 모두 소비된 뒤에만 발생한다.
- `DialogueBeat`의 표면·내부 감정은 집필 메타데이터이며 런타임 감정 축으로 증식시키지 않는다.
- 공명·압력은 장면 진입 시 검수된 변주를 선택한다. 장면 안의 모든 대사를 두 축의 조합으로 실시간 합성하지 않는다.
- 핵심 기억은 발견 즉시 고정 영역에 놓고 덱 추첨에서 제외한다. 핵심 기억 미추첨으로 보스 진행이 막히면 실패다.
- 공명 판정은 `dramaticCue`·필요 기억·공명 단계가 소유한다. 실제 표정 파일과 렌더링 프레임은 판정을 바꾸지 않는다.
- 핵심 단서에 감정 치환 폴백을 사용하지 않는다. 필수 표정·관찰 문장이 없으면 콘텐츠 검증 실패다.
- 표정 선택은 `characterId + appearanceSet + emotionTag`로 제한한다. 다른 시대 외형으로 자동 폴백하지 않는다.

## 7. 반복·겹침 방지

- 같은 대사 ID는 기본 10회 발화 동안 재선택 금지.
- 같은 의도·같은 화자 조합은 2회 연속 금지.
- 전투 일반 대사는 한 라운드 최대 1개, 보스 힌트와 사망 대사는 예외.
- 우선순위 3의 이야기 대사가 재생 중이면 낮은 우선순위 대사는 폐기한다.
- 우선순위 2 이상끼리 충돌하면 큐에 최대 2개만 보관한다.
- 4초 안에 읽지 못할 길이의 전투 대사는 자동으로 전투를 멈추지 않는다. 핵심 장면은 명시적으로 일시정지한다.
- 이미 알아낸 보스 힌트는 장문 재설명 대신 짧은 확인 대사로 교체한다.

## 8. 관계와 사상

D1 관계치는 화면에 숫자로 노출하지 않는다. 공명은 `낯섦 → 인정 → 신뢰 → 유대`, 압력은 `안정 → 균열 → 붕괴 직전`의
두 축만 런타임 상태로 둔다. 표면 감정·내부 감정·숨기는 것은 대사 비트의 집필 필드이며 별도 시뮬레이션 축이 아니다.

- 페일: 결속. 관계와 이름을 부여함으로써 짐승이 단순한 본능을 넘어선다고 믿는다.
- 카노: 화답. 숭배받는 존재라면 실제로 응답해야 한다고 믿지만 신의 역할 뒤에 두려움을 숨긴다.
- 네모/바치칼: 결속. 과거를 없애지 않고 이름과 책임을 다시 받아들이려 한다.
- 박니은: 이해 불가능성을 믿지만, 이해하지 못하는 세계를 혼자 지키는 모순을 산다.
- 알제: 책임을 피하고 싶지만 옛 시스템과 생존자를 방치하지 못한다.
- 워어즈: 관찰자. 플레이어에게 정답을 주지 않고 선택이 쌓이는 모습을 본다.
- 항해사: 들음과 책임. 서로 다른 답을 연결하지만 타인의 미래를 대신 결정하지 않는다.

선택이 특정 사상 점수를 올려 엔딩을 자동 결정해서는 안 된다. 사상 기록은 동료 반응과 보스 질문의 문맥을 바꾸며,
마지막 판단은 플레이어가 직접 선택한다.

## 9. 성능·에셋 선행 관문

테메로세 카드군은 메타데이터의 이미지 형식과 실제 페이로드가 다르다. D1 콘텐츠 컴파일 전에 다음을 해결한다.

1. 확장자 선언이 아니라 실제 바이트 시그니처로 PNG/JPEG/WebP를 판별한다.
2. 네 카드의 이미지 에셋을 모두 감사하되 한 번에 번들하지 않고, 사람이 실물을 확인한 D1 허용 목록만 별도 콘텐츠팩으로 만든다.
3. 로비에는 테메로세 에셋과 Phaser를 넣지 않는다. 캐비닛 진입 뒤 필요한 장면 단위로 로드한다.
4. 초상은 192px·384px 파생본, 전투 컷인은 화면 크기별 파생본을 사용한다.
5. 장면 이탈 시 Object URL, 텍스처, 오디오, 입력, Phaser Scene을 모두 해제한다.
6. 성인 상태·행위를 뜻하는 이름이 포함된 항목과 별도 안전 목록에 없는 에셋은 컴파일 실패로 처리한다. 이름 필터 통과는
   안전 승인으로 간주하지 않는다.
7. 감사에서는 파일 수, 정확 중복, 고유 구도, 고유 감정, D1 사용 가능성, 관찰 단서 가능성, 컷인 해상도를 분리한다.
8. 핵심 인물 8~12장 같은 수량은 탐색 목표일 뿐 합격선이 아니다. 필요한 감정 기능을 실제로 표현할 수 있는지가 관문이다.
9. 핵심 관찰 표정은 자동 폴백 금지, 일반 연기 표정은 명시적 동의어 폴백만 허용한다.

## 11. 완료 관문

- 첫 입력 뒤 30초 안에 박니은이 등장하고 5분 안에 피쿼드·메트로·인기 동료 중 둘을 확인한다.
- 플레이어가 쓰러져 깨어나는 대신 폐허를 직접 수색하고 첫 행동으로 단말기를 깨운다.
