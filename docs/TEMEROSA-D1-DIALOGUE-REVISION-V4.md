## A. 현재판 문제 진단

| 장면 | 판정 | 이유 | 사용자가 실제로 느낄 문제 |
|---|---|---|---|
| 0 죽은 단말기 | 압축+재작성 | 첫 행동 결과와 니은 등장이 별개 노드로 분할, 니은 표정 2종 고정 | 첫 30초의 기습감 반감. 선택이 시스템 문구 차이로만 보임 |
| 1 마지막 인사부 | 재작성 | 알제 전 대사가 `surprised` 한 장, 등록 3선택 결과 무차별, 직책 설명 낭독조 | 알제가 내내 놀란 얼굴. 어떤 선택을 해도 같은 발급 문구 |
| 2 함께 갈 두 사람 | 확장 | 선택창 3연속(반응 0줄), 니은 3분째 증발, 재주행 유도 부재 | 대화가 아니라 메뉴 조작. 끝났는데 "다시 하고 싶다"는 감각 없음 |

현재판 대표 경로는 약 31클릭으로 보고됐으나 V4에서 노드를 합치는 것만으로는 클릭이 줄지 않는다.
현재 엔진은 대사 한 줄마다 진행 입력을 받고 마지막 줄의 입력으로 다음 노드에 진입하기 때문이다.
V4.1은 아래 클릭 행렬처럼 `대사 진행 + 선택 + 동료 2명 선택 + 편성 확정`을 실제 입력 단위로 다시 센다.
읽기 시간 4.5~6분은 실기기 계측 전까지 목표치이며 실측값으로 표현하지 않는다.

## B. 개정된 전체 흐름 (고유명사 없이)

폐허에서 물자를 뒤지던 당신이 죽은 기계를 깨운다. 무엇을 먼저 했느냐에 따라 하나를 지키고
하나를 영영 잃는다 → 화면 너머에서 낯선 여자가 통신을 걸어온다. 날카롭지만 당신을 살리려
한다. 자기는 "움직이면 세상 끝도 같이 움직여서" 올 수 없다며 안쪽의 남자를 찾으라 한다 →
게임기만 보던 무기력한 남자. 그러나 시스템이 당신을 "정리 대상"으로 찍자, 그는 백 년 묵은
직책 서류를 꺼내 당신을 살린다. 조건은 하나 — 살아서 돌아올 것 → 세 사람이 나타난다.
당신에게서 아는 기분이 난다는 사람, 감독을 자처하는 서리의 사람, 죽지 말라고 경고하는 창의
사람. 각자 조건과 거부권을 걸고, 당신은 둘을 고른다 → 호칭을 정하고, 관계의 경계를 정하고,
통신 너머의 여자가 당신의 편성을 평가한다 → 팽팽한 농담과 함께 첫 항로로 출발한다.
화면은 말한다: 다른 둘을 골랐다면 다른 대화가 있었다고.

감정 곡선: 고요(수색) → 기습(통신) → 위기(폐기 경고) → 안도+호기심(등록) →
긴장(세 사람의 조건) → 결속(출발) → 여운(재주행 암시).

#### `departure-kano-nemo` (dialogue)
- **L1** `pale`(미선택) — "다녀와. 이상한 걸 찾으면 내 몫도 남겨 둬." · `review-pale-smile` · → L2
- **L2** `kano` — "시간을 되돌리는 일은 금지합니다." · `review-kano-smirk` · → L3

- **L4** `kano` — "그건 전술 신호예요!" · `[승인 필요] Kano_upset` · → `pilot-complete`

#### `pilot-complete-message` (dialogue) — 기존 완료 화면 앞에 배치
- **L1** `system` — "제1장 파일럿 구간 완료 — 첫 항로 진입 준비."
- **L2** `system` — "다른 두 사람과 출발하면, 보지 못한 대화와 단서가 열립니다." [재주행 유도 — V3 §14 정본 문구 복원]

두 번째 문장은 조합 수학과 문맥을 Gemini가 재검토해야 한다. V4.1에서는 한국어 문장을 임의 수정하지
않고 검토 필요 상태로 둔다. L2 진행 후 기존 `pilot-complete` 노드로 이동한다.

#### `pilot-complete` (complete)
- 현행 완료 화면과 선택 동료·보존·상실 요약을 유지한다.
- 등록 선택은 새 문장을 만들지 않고 사용자가 눌렀던 선택지 라벨을 그대로 요약에 재표시한다.

## F. 구현 반영 지시서 (코덱스용 — 코드는 아직 수정하지 말 것)

1. `content.ts` 노드 교체: 대응표대로 병합·신설. `pact-detail` 삭제, `pact-ans-ask` 뒤에는 `pact-accept-after-detail`을 배치한다. 미수락 출항을 금지한다.
2. `nieun-return` 조합 변주: contracts에 조합 조건 라인이 없으면 `departure-*`처럼 조합별 3노드(`nieun-return-{pk,pn,kn}`) + core 가상 라우트로 구현.
3. `pale-boundary-check` branch: 네모 미편성 시 `nemo-name` 생략 라우팅은 현행 core 패턴 확인 후 동일 적용.
4. 보존/상실은 대사 문자열을 정규식으로 해석하지 않는다. `StoryMemory.preservedResourceId/lostResourceId`를 사용해 대사 상단 또는 결과 카드에 구조화된 칩으로 표시한다. V4 대사 속 괄호는 원고 표기일 뿐 저장 계약이 아니다.
5. `core.ts`의 `departure` 가상 라우트에 주석 추가: "content에 노드 없음 — 조합 해석 라우트" (오인 방지).
6. **에셋 승인 요청 12건 (오너 시각 검수 → 0.4.0 허용 목록)**:
   알제 `Alger_standing`·`Alger_smirk`·`Alger_disappointed`·`Alger_smile` /
   카노 `Kano_standing`·`Kano_angry`·`Kano_upset` / 페일 `Pale_standing`·`Pale_smirk` /
   바치칼 `Bacikal_standing`·`Bacikal_smile`·`Bacikal_disappointed`.
   전부 `*/finale-current` 세트 확인 필수(외형 여권 절차). 승인 전에는 관련 비트를 릴리스 팩에서 차단하며 감정 치환 폴백을 사용하지 않는다.
7. 등록 3선택 회수 플래그(`nameBlank`/`noFailureTerms`/`survivorHint`) 저장. 이번 구간에서는 완료 화면에 기존 선택 라벨을 재표시하고, 장면 4·7·9 변주는 후속 미구현으로 명시한다.
8. `alger-evidence`는 `playerApproach`에 따라 전용 증거 1개와 공통 질문 1개만 생성한다. `first-ask`용 `evidence-channel`은 Gemini 대사 승인 전 구현 차단 항목이다.
9. 한 대사 안의 `smirk→surprised` 같은 표정 전환은 현재 계약으로 표현하지 않는다. 전환 지점을 별도 `DialogueLine`으로 나누고 각 줄에 하나의 `assetId`만 배정한다.
10. 완료 시스템 2줄은 `CompleteNode`에 억지로 넣지 않고 `pilot-complete-message` 대화 노드로 만든 뒤 현행 완료 화면에 연결한다.
11. 콘텐츠팩 로더는 승인된 0.4.0 매니페스트가 실제 생성된 뒤에만 해당 버전을 추가한다. 매니페스트 누락이나 필수 에셋 누락은 로딩 실패로 처리한다.
12. e2e: 선택창 연속 구간(호칭→경계→니은→수락), 상실 증거 차단, 미수락 출항 차단, 세 조합 클릭 수를 회귀 테스트한다.

## G. 오너용 최종 브리핑

**기존판의 문제**: 세 가지였습니다. ①알제가 처음부터 끝까지 놀란 표정 한 장이었고 ②동료를 고른 뒤
선택창만 세 번 연속으로 떠서 대화가 아니라 메뉴 조작처럼 느껴졌고 ③앞에서 매력적이던 니은이
편성 장면에서 완전히 사라진 채 게임이 뚝 끝났습니다.

**개정판의 변화**: 선택마다 반응 대사가 붙고, 표정이 장면 안에서 실제로 바뀌고(에셋 승인 후),
편성이 끝나면 니은이 돌아와 당신의 조합을 한 줄로 평가합니다 — 조합마다 평가가 달라서
"다른 둘을 골랐으면 뭐라고 했을까"가 자연스럽게 궁금해집니다. 무엇을 지키고 잃었는지는
[보존]·[상실] 태그로 한눈에 보입니다.

**설계상 입력 수**: 바로 수락하면 40~42입력, 위험 설명을 들으면 42~44입력입니다. 읽기 시간
4.5~6분은 아직 목표치이며 실기기에서 측정하기 전에는 실측값으로 간주하지 않습니다. 더 늘려야
한다면 장면 3 이후 콘텐츠로 늘려야지, 0~2 구간을 부풀리면 안 됩니다.

**직접 확인할 장면 3개**: ①첫 행동 4종을 바꿔가며 니은의 첫 반응이 각각 다른지 ②침묵 선택의
벽 두드리기 ③편성 후 니은의 조합 평가(세 조합 모두).

**구현 전 차단 항목**: ①에셋 승인 12건 ②`evidence-channel` 한국어 대사 Gemini 작성·검수
③완료 재주행 문장 Gemini 재검토. 등록 선택의 장면 4·7·9 회수는 이번 구현 범위가 아니며,
이번 구간에서는 저장과 완료 요약까지만 맡습니다.
