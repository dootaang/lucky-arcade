# SPEC-A34 — 파이브 카드 드로 맞레이즈

> 상태: 구현·검증 완료 (2026-07-29). 관리자 시험판 전용이며 공개 승격은 별도 결정이다.

## 1. 목적

`five-card-draw/0.3`은 베팅을 1단위, 레이즈를 2단위에서 닫았다. 플레이어가 레이즈하면 NPC에게 남는
선택이 폴드·콜뿐이라 강한 패와 공격적인 성격도 판돈을 다시 올릴 수 없었다. 0.4는 고정 리밋을 한 단계
확장해 **한 베팅 거리당 맞레이즈 한 번**을 허용한다.

## 2. 규칙 계약

- 앤티: 좌석마다 1단위
- 베팅: 거리 판돈을 1단위로 연다.
- 레이즈: 1 → 2단위
- 맞레이즈: 2 → 3단위
- 3단위에서는 폴드·콜만 가능하며 더 올릴 수 없다.
- 교환 전·교환 후 두 거리의 최대 기여는 `앤티 1 + 3 + 3 = 7단위`다.
- 행동 저장값은 계속 `raise`다. 2단위 판돈을 3단위로 올린 표현만 화면에서 `맞레이즈`로 읽는다.

계약 버전:

- `five-card-draw-state/0.4`
- `temerosa-five-card-draw/0.4`
- `temerosa-five-card-draw-preview/0.2`

시험판은 최대 200 P × 7단위인 1,400 P를 실제로 시험할 수 있도록 새 시험 지갑을 2,000 P에서 시작한다.
기존 0.3 상태와 0.1 시험 봉투는 읽지 않으며, 실지갑·공개 전적은 여전히 사용하지 않는다.

## 3. NPC 판단

NPC는 자기 패와 공개된 정보만 사용한다. 맞레이즈 가능 여부가 생겨도 상대 비공개 패는 관측값에 추가하지
않는다.

- 족보 강도와 키커 세부값
- 교환 장수·공개 표정·현재 거리의 공개 행동
- 팟 오즈와 참가 인원
- `riskAppetite`, `deceptionBias`, `consistency`, `signalAttention`, `signalTrust`
- 판 시작 때 고정한 가치·보호·허세·함정·포기 계획

맞레이즈 기준은 첫 레이즈보다 높다. 공격적·기만적인 NPC는 약한 패로도 낮은 확률의 맞레이즈를 시도할
수 있지만, 3단위 상한에서는 어떤 성격도 다시 레이즈하지 않는다.

## 4. 표현과 초보자 안내

- 플레이어가 2단위 레이즈를 마주하면 버튼과 설명을 `맞레이즈`로 표시한다.
- 비용은 고정된 2가 아니라 `현재 거리 판돈 + 1 - 내 기여`로 계산한다.
- NPC 맞레이즈 때 좌석 상태에 `맞레이즈`가 보이고, 기존 칩 비행과 팟 맥박을 재사용한다.
- 표현 이벤트의 `counterRaise`는 이전 상태의 거리 판돈이 2단위였는지로 파생한다. 판정과 결과 해시에
  별도 표현 필드를 넣지 않는다.

## 5. 검증 관문

- 강공 플레이어를 둔 4인 2,000시드에서 맞레이즈가 발생한 판의 비율은 20~40%다.
- 한 거리의 `raise` 기록은 최대 2회다.
- 중간 성격의 개별 맞레이즈율은 2~8%이며, 공격형과 신중형의 차이는 4%p를 넘는다.
- 테메로세 30인 전체의 평균 맞레이즈율은 1.5~7%, 최고 인물도 12% 미만이다.
- 동일 시드·동일 입력은 동일 상태와 `resultId`를 만든다.
- 모든 좌석 기여는 7단위를 넘지 않고, 팟 합계와 지급 합계가 일치한다.
- 10,000시드 자동 완주, 전체 `pnpm check`, Playwright 전수를 통과한다.

## 6. 비범위

공개 승격, 실지갑 영수증, 전용 대사, 상대별 전적은 이번 작업에 포함하지 않는다. 맞레이즈는 관리자
시험판에서 손맛과 NPC 분포를 확인하기 위한 규칙 고도화다.
