# SPEC-A27 — 짝맞추기 1대1 NPC 대전

> 상태: v1.0 구현 완료 · 검증 대기 (2026-07-26). 선행: [SPEC-A22](./SPEC-A22-match-pairs.md).
>
> 오너 결정: 기존 1인 공개판을 플레이어 대 NPC 한 명의 무료 대전으로 교체한다. 이 게임은 포인트를 지급하지 않는다.

## 1. 공개 규칙

- 쉬움은 6쌍, 보통은 8쌍이다.
- 플레이어와 NPC가 번갈아 두 장을 뒤집는다.
- 짝을 맞히면 그 두 장을 자기 점수로 가져가고 한 번 더 진행한다.
- 틀리면 두 장을 잠시 공개한 뒤 닫고 상대에게 차례를 넘긴다.
- 모든 짝을 가져가면 더 많은 짝을 얻은 쪽이 승리하며 같은 수면 무승부다.
- 무료 입장이고 판돈·완주 보상·포인트 발행이 없다.
- 카드 앞면은 계속 이미지 하나만 표시한다. 인물명·표정명·툴팁은 카드에 표시하지 않는다.

## 2. 상대 풀

`temerosa-margin/0.8.0`의 감사된 카지노 NPC 중 `neutral/pleased/tense/despair` 4종이 모두 있는 30명을 쓴다.

- 바치칼은 제외한다.
- 네모는 감사팩의 마법소녀 네모 4종으로 고정한다.
- 준비 화면에서 직접 선택하거나 결정론적 `무작위 상대`로 바꿀 수 있다.
- 30명 썸네일은 `sm`, 선택한 상대와 게임판은 `md`를 쓴다.
- 선택한 상대가 바뀔 때 그 인물의 표정 4종만 선로드한다. 30명 전체 `md` 선로드는 금지한다.

## 3. NPC가 아는 정보

NPC는 실제로 앞면이 공개된 카드만 기억한다. 숨은 `cards` 배열은 선택 함수의 인자가 아니다.

```ts
interface MatchPairsNpcRead {
  seed: string;
  sequence: number;
  turnNumber: number;
  cardCount: number;
  openIndexes: readonly number[];
  unavailableIndexes: readonly number[];
  memory: readonly MatchPairsMemoryEntry[];
}
```

기억 항목은 `index`, 공개 당시의 `pairId`, `seenAtTurn`, `confidence`만 갖는다. 이미 가져간 짝은 기억에서 지운다.
기억 용량을 넘으면 신뢰도가 낮고 오래된 항목부터 잊는다. 회상 실패는 시드 난수로 결정되며 저장 재생에서 같다.

선택 우선순위는 다음과 같다.

1. 기억 속에 완성된 짝이 있고 회상에 성공하면 그 짝을 연다.
2. 첫 장을 연 뒤 그 상대 위치를 기억하고 회상에 성공하면 상대 카드를 연다.
3. 탐색 성향에 따라 아직 기억에 없는 위치를 연다.
4. 남은 기억 중 신뢰도와 일관성에 따라 한 위치를 다시 확인한다.

## 4. 성격 변환

새로운 캐릭터 설정을 만들지 않는다. 도둑잡기에서 CHARX 근거로 승인된 공통 행동 어휘를 짝맞추기용으로 변환한다.

- `signalAttention` → 기억 용량과 기본 회상 정확도
- `consistency` → 기억 유지율과 같은 상황의 선택 일관성
- `reorderActivity` → 미확인 카드를 먼저 탐색하는 성향

수치는 UI에 성격 사실처럼 표시하지 않는다. 이 변환은 앱 어댑터가 소유하며 두 게임의 순수 코어는 서로 import하지 않는다.

## 5. 상태와 입력

계약은 `match-pairs/0.2`, `match-pairs-state/0.2`다. 상태에는 다음을 추가한다.

- `currentTurn`, `revealActor`, `opponentId`
- 플레이어/NPC별 `claims`
- `npcMemory`, `npcReaction`
- `turnNumber`, `lastResolution`, `outcome`

입력은 `player-reveal(index)`, 인덱스를 받지 않는 `npc-reveal`, `resolve`, 상대 선택·무작위 선택, 시작·재시작이다.
NPC의 실제 인덱스는 순수 리듀서 안에서 공개 기억을 이용해 정한다. 모든 입력과 선택 결과는 WAL 재생으로 같은 결과 해시를 만든다.

## 6. 시간과 복구

- NPC 첫 공개는 약 420ms, 두 번째 공개는 약 560ms 뒤에 진행한다.
- 불일치는 약 800ms 보여 준 뒤 닫는다.
- 일시정지와 탭 비활성화 중에는 NPC·판정 타이머의 남은 시간을 보존한다.
- 시간값은 상태·WAL·결과 해시에 넣지 않는다.
- 새 세션 ID는 `temerosa-match-pairs:versus-1`이다. 0.1의 1인 진행 상태를 0.2 규칙으로 재생하지 않는다.
- 완료 전적에는 플레이어와 실제 NPC의 순위·이름·참가자 ID를 함께 남긴다.

## 7. 검증 관문

이 커밋에서는 오너 지시에 따라 검증을 실행하지 않는다. 다음 검증 차례에 아래를 수행한다.

- 10,000시드 결정론 완주와 동일 입력 결과 해시
- 일치 시 차례 유지, 불일치 시 차례 교대, 무승부 판정
- NPC 기억 용량·회상·미확인 탐색과 숨은 카드 비입력 계약
- 30명 풀, 바치칼 제외, 네모 마법소녀 세트, 초상 4종 존재
- 저장 중 checking/NPC 차례 복구
- 일시정지·백그라운드 중 NPC 진행 정지
- 카드 앞면의 이름·표정명·툴팁 미노출
- 경계 검사, 전체 타입 검사, 초기 JS gzip 200 KiB, 전체 E2E
