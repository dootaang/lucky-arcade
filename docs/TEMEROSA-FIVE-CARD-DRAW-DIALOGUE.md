## 1. 분업·안전 계약

- 코덱스가 사건 의미와 캐릭터 해석을 고정하고, 제미나이 프로가 자연스러운 한국어를 검수한다.
- 숨은 패, 상대 족보, 다음 행동이나 판정 결과를 미리 누설하지 않는다.
- 한 문안은 기본 한 박자다. 꼭 필요할 때만 `<br>`로 두 박자를 쓴다.
- 폴드한 패를 봤다고 말하지 않는다. 쇼다운 승패 문안도 족보를 발명하지 않는다.
- 문서가 정본이다. 코드에서 문안을 고치지 않는다.

## 2. 사건 의미

| event | 화자 기준 상황 |
|---|---|
| `table-open` | 패가 배분되고 대국이 시작됐다. 아직 상대 패는 모른다. |
| `check` | 화자가 추가 판돈 없이 차례를 넘겼다. |
| `bet` | 화자가 먼저 판돈을 걸었다. |
| `call` | 화자가 상대의 판돈을 받아 승부를 이었다. |
| `raise` | 화자가 판돈을 한 단계 올렸다. |
| `counter-raise` | 상대 레이즈에 다시 한 단계 올려 맞섰다. |
| `fold` | 화자가 패를 공개하지 않고 승부를 포기했다. |
| `stand-pat` | 화자가 한 장도 교환하지 않았다. 강한 패라는 뜻일 수도 허세일 수도 있다. |
| `draw-one` | 화자가 카드 한 장을 교환했다. |
| `draw-many` | 화자가 카드 두세 장을 교환했다. |
| `showdown-win` | 공개 승부 또는 상대 전원 폴드로 화자가 팟을 얻었다. |
| `showdown-loss` | 화자가 팟을 얻지 못했다. 폴드했을 수도 쇼다운에서 졌을 수도 있다. |
