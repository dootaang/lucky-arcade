# SPEC-A28 — 인디언 포커 1대1 개정

> 상태: v1.0 구현 완료·검증 중 (2026-07-26). 선행: A11 트럼프 덱, A23 공용 판돈 영수증.
>
> [SPEC-A25](./SPEC-A25-casino-card-tables-through-holdem.md)의 인디언 포커 0.2를 대체한다.

## 1. 플레이 계약

- 플레이어 한 명과 선택한 테메로세 NPC 한 명이 5라운드를 치른다.
- 52장 한 덱을 대국 시작 때 한 번만 결정론적으로 섞고, 라운드마다 두 장을 교체 없이 소비한다.
- 자신의 카드는 뒤집힌 채 이마에 놓이고 상대 카드만 보인다. 쇼다운에서만 자신의 카드를 공개한다.
- 숫자만 비교한다. J=11, Q=12, K=13, A=14이며 같은 숫자는 무승부다.
- 두 사람은 10칩으로 시작하고 라운드마다 1칩씩 앤티를 낸다.
- NPC가 체크하면 플레이어는 체크 또는 1칩 레이즈를, NPC가 레이즈하면 콜 또는 폴드를 고른다.
- 플레이어 레이즈에 NPC는 콜 또는 폴드한다. 첫 버전은 재레이즈와 올인을 두지 않는다.
- 5라운드가 끝나거나 어느 한쪽 칩이 0이 되면 대국을 마친다.

## 2. 트럼프 자산

`packages/card-table`이 무늬·숫자·ID·52장 덱·결정론 셔플의 정본이다. A~10은 기존 SVG를,
J·Q·K는 A11에서 감사한 WebP 아틀라스를 쓴다. `StandardPlayingCard`가 두 표현을 같은 반응형
크기로 렌더링한다. 조커는 이 게임의 덱에 들어가지 않는다.

아틀라스는 앱 공용 로더가 한 번만 읽는다. 저밀도 소형 화면은 `sm`, 나머지는 `md`를 고르며
카지노 카드 테이블들과 같은 캐시를 공유한다.

## 3. NPC와 정보 경계

도둑잡기의 감사된 30인 좌석 풀을 재사용한다. 바치칼은 제외하고 네모는 `npc-*` 마법소녀 외형만
통과시킨다. 재배열 활동성·신호 주의·미끼 성향·일관성을 각각 위험 선호·판독 정확도·기만 성향·
행동 일관성으로 변환한다.

NPC 판단 인자는 플레이어의 현재 공개 카드, 이전에 공개된 카드, 라운드와 칩, 플레이어의 과거
레이즈·폴드뿐이다. NPC 자신의 현재 카드는 인자에 없고, 미지 카드 확률 계산에도 미지 카드로 남는다.
표정은 플레이어 카드에 대한 결정론 신호이며 판정 상태를 바꾸지 않는다.

## 4. 포인트와 복구

판돈은 10·50·200 P 중 하나다. 시작 전에 선택액만 예약하고 내부의 10칩으로 바꾼다. 종료 반환액은
`floor(판돈 × 플레이어 칩 / 10)`이므로 0~2배 범위다. 예약·정산은 A23 영수증으로 멱등 처리한다.

저장 계약은 `indian-poker/0.3`, `indian-poker-state/0.2`, 팩 `temerosa-indian-poker/0.3`, 세션
`indian-poker:heads-up-1`이다. 예약 뒤 상태 저장 전에 종료해도 영수증의 상대 ID와 딜 시드로 같은 판을
복원한다. 0.2 세션은 이어 붙이지 않는다.

## 5. 표현 계약

- 준비 화면에는 빈 카드 자리만 보이고 패를 미리 만들지 않는다.
- 딜 때 두 카드가 들어오며 플레이어 카드는 쇼다운에서 실제 Y축 뒤집기로 공개한다.
- `prefers-reduced-motion`에서는 딜과 뒤집기 전환을 제거한다.
- NPC 응답 대기는 일시정지와 탭 백그라운드에서 남은 시간을 보존한다.
- 상대가 정해진 뒤에만 해당 인물의 표정 세트를 선로드한다.

## 6. 검증 관문

1. 52장과 ID가 중복 없이 고정되고 같은 시드 셔플이 같다.
2. 1,000시드 자동 대국이 모두 종료되며 항상 두 사람의 칩 합이 20이다.
3. 한 대국의 10장은 중복되지 않고, 동일 시드·입력의 결과 해시가 같다.
4. NPC 판독 구조에 현재 자신의 카드가 존재하지 않는다.
5. 30인 카트리지, 바치칼 제외, 마법소녀 네모 제한이 유지된다.
6. 새로고침 뒤 같은 라운드와 영수증으로 복구하며 중복 정산하지 않는다.
7. 데스크톱 E2E에서 뒷면→공개→다음 라운드→새로고침→완료 흐름이 통과한다.
8. 경계 검사와 초기 JavaScript gzip 200 KiB 예산을 지킨다.
