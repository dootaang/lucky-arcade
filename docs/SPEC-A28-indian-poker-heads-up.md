# SPEC-A28 — 인디언 포커 1대1 개정

> 상태: v2.0 구현·검증 완료 (2026-07-29). 선행: A11 트럼프 덱, A23 공용 판돈 영수증.
>
> [SPEC-A25](./SPEC-A25-casino-card-tables-through-holdem.md)의 인디언 포커 0.2를 대체한다.

## 1. 플레이 계약

- 플레이어 한 명과 선택한 테메로세 NPC 한 명이 **5라운드 또는 7라운드**를 치른다. 기본값은 7라운드다.
- 52장 한 덱을 대국 시작 때 한 번만 결정론적으로 섞고, 라운드마다 두 장을 교체 없이 소비한다.
- 자신의 카드는 뒤집힌 채 이마에 놓이고 상대 카드만 보인다. 쇼다운에서만 자신의 카드를 공개한다.
- 숫자만 비교한다. J=11, Q=12, K=13, A=14이며 같은 숫자는 무승부다.
- 두 사람은 12칩으로 시작하고 라운드마다 1칩씩 앤티를 낸다.
- 첫 행동 좌석은 딜 시드로 정하고 라운드마다 교대한다. 양쪽 모두 체크하거나 1·2칩을 베팅할 수 있다.
- 베팅을 받은 쪽은 콜 또는 폴드를 고른다. 재레이즈와 올인은 두지 않는다.
- 폴드한 플레이어 카드는 공개 이력에서 숨긴다. NPC는 그 라운드 동안 플레이어 카드를 실제로 봤으므로 이후 자기 판단 이력에는 남는다.
- 선택한 라운드 수가 끝나거나 어느 한쪽 칩이 0이 되면 대국을 마친다.

## 2. 트럼프 자산

`packages/card-table`이 무늬·숫자·ID·52장 덱·결정론 셔플의 정본이다. A~10은 기존 SVG를,
J·Q·K는 A11에서 감사한 WebP 아틀라스를 쓴다. `StandardPlayingCard`가 두 표현을 같은 반응형
크기로 렌더링한다. 조커는 이 게임의 덱에 들어가지 않는다.

아틀라스는 앱 공용 로더가 한 번만 읽는다. 저밀도 소형 화면은 `sm`, 나머지는 `md`를 고르며
카지노 카드 테이블들과 같은 캐시를 공유한다.

## 3. NPC와 정보 경계

도둑잡기의 감사된 30인 좌석 풀을 재사용한다. 바치칼은 제외하고 네모는 `npc-*` 마법소녀 외형만
통과시킨다. 인디언 포커 전용 성격은 `aggression`·`bluffFrequency`·`slowPlay`·`estimationNoise`·
`tellReliability`·`tiltResponse` 여섯 축이다. 도둑잡기 성격을 런타임에 변환하지 않고 별도 동결 데이터로 둔다.

NPC 판단 인자는 플레이어의 현재 공개 카드, 이전에 공개된 카드, 라운드와 칩, 플레이어의 과거
베팅·폴드뿐이다. NPC 자신의 현재 카드는 인자에 없고, 미지 카드 확률 계산에도 미지 카드로 남는다.
표정은 플레이어 카드에 대한 결정론 신호이며 판정 상태를 바꾸지 않는다.

불운한 고액 카드 연속은 셔플을 조작해 막지 않는다. 대신 화면에 이미 공개된 카드와 A·K·Q·J 잔여 추정의
근거를 남기고, 완료 화면에서 시드·카드·행동·결과 해시를 복사할 수 있게 한다. 같은 물리 카드 ID는 한
대국에서 두 번 나올 수 없으며, 동일한 무늬·숫자가 반복됐다는 제보는 감사 기록으로 엔진과 표시를 구분한다.

## 4. 포인트와 복구

판돈은 10·50·200 P 중 하나다. 시작 전에 선택액만 예약하고 내부의 10칩으로 바꾼다. 종료 반환액은
`floor(판돈 × 플레이어 칩 / 12)`이므로 0~2배 범위다. 예약·정산은 A23 영수증으로 멱등 처리한다.

저장 계약은 `indian-poker/0.4`, `indian-poker-state/0.3`, 팩 `temerosa-indian-poker/0.4`, 세션
`indian-poker:heads-up-2`다. 예약 뒤 상태 저장 전에 종료해도 영수증의 상대 ID·라운드 수·딜 시드로 같은 판을
복원한다. 구형 진행 판은 이어 붙이지 않고 예약 판돈을 전액 환불한다. 구형 완료 전적은 새 전적과 합쳐 표시한다.

## 5. 표현 계약

- 준비 화면에는 빈 카드 자리만 보이고 패를 미리 만들지 않는다.
- 준비 화면에서 5·7라운드를 고르며 7라운드를 기본 선택으로 표시한다.
- 딜 때 두 카드가 들어오며 플레이어 카드는 쇼다운에서 실제 Y축 뒤집기로 공개한다.
- 중앙에는 공개된 라운드 카드와 A·K·Q·J의 공개 수량을 작은 기록 레일로 남긴다.
- 첫 화면의 도움말은 상대 카드 보기·표정의 불확실성·폴드의 손실 제한만 짧게 설명한다.
- `prefers-reduced-motion`에서는 딜과 뒤집기 전환을 제거한다.
- NPC 응답 대기는 일시정지와 탭 백그라운드에서 남은 시간을 보존한다.
- 상대가 정해진 뒤에만 해당 인물의 표정 세트를 선로드한다.

## 6. 검증 관문

1. 52장과 ID가 중복 없이 고정되고 같은 시드 셔플이 같다.
2. 5·7라운드 각각 1,000시드 자동 대국이 모두 종료되며 항상 두 사람의 칩 합이 24다.
3. 한 대국의 최대 10·14장은 중복되지 않고, 동일 시드·입력의 결과 해시가 같다.
4. NPC 판독 구조에 현재 자신의 카드가 존재하지 않는다.
5. 30인 카트리지, 바치칼 제외, 마법소녀 네모 제한이 유지된다.
6. 새로고침 뒤 같은 라운드와 영수증으로 복구하며 중복 정산하지 않는다.
7. 데스크톱 E2E에서 기본 7 확인→5 선택→뒷면→공개→다음 라운드→새로고침→완료 흐름이 통과한다.
8. 경계 검사와 초기 JavaScript gzip 200 KiB 예산을 지킨다.
9. 완료 감사 기록의 시드·카드·행동·결과 해시가 같은 재생에서 글자 단위로 같다.
