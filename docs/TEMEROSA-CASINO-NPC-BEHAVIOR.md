# 테메로세 카지노 NPC 행동 성격표

> 상태: 35명 구현 확정 (2026-07-26).
>
> 원문은 싣지 않는다. 기존 CHARX 교차검수 결과인 [기존 9인 대사집](./TEMEROSA-OLD-MAID-DIALOGUE.md)과
> [신규 26인 명부](./TEMEROSA-CASINO-NPC-ROSTER.md)를 근거로 게임 행동만 도출했다.

## 읽는 법

각 축은 사실 묘사가 아니라 도둑잡기에서 관찰 가능한 행동으로 번역한 값이다.

`활동/정직/미끼 · 일관성 · 위치 · 관찰/역독해` 순서로 적는다. 예를 들어
`낮/낮/높 · 일정 · 중앙 · 높/의심`은 손을 자주 만지지는 않지만, 만지면 조커보다 일반 카드 미끼를
일정하게 만들고 상대의 재배열은 함정으로 읽는다는 뜻이다.

## 경계

- 이 표를 UI의 성격 라벨로 노출하지 않는다. 플레이어는 반복 대국으로 습관을 읽는다.
- 수치가 아니라 제한된 단계만 기록한다. 원문 근거가 바뀌면 표와 코드 값을 함께 고친다.
- 개인 카드 NPC는 이 표에 자동 편입하지 않는다. 근거가 없으면 `tellStyle` 기본 행동을 쓴다.
