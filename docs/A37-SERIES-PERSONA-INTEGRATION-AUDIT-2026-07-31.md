# A37 시리즈 페르소나 통합 감사 — 2026-07-31

## 결론

네 병렬 작업물은 하나의 `series-persona` 후보 계약으로 통합했다. 다만 라이브 경제 전환은 아직 잠겨 있다.
명시적인 `flowEconomy` 플래그뿐 아니라 동결 감사 상태도 `ready`여야 전환되며, 현재 상태는
`blocked: house-service-curtailment`다. 기본 웹 런타임은 계속 `npc-ledger/1.1`을 사용한다.

## 통합 범위

- 정본 명부: 116개 시리즈·출전 인격. 같은 인물이라도 작품과 시기가 다르면 별도 NPC다.
- 원장 후보: 99개. `confirmed` + (`casino-ready` 또는 `ledger-only`) + 명시적 active 프로필의 교집합이다.
- 게임 좌석 후보: 80개 `casino-ready` 신원이다.
- 기존 승계: 에스더·리엘·마법소녀 네모를 포함해 최종 경제 후보는 102개다.
- 워어즈 두 신원은 하우스 전용이며 개인 도박 지갑을 만들지 않는다.
- 바치칼 두 신원은 명부와 에셋에 보존하지만 일반 참가 풀에서 제외한다. 기존 `bacikal`과 `nemo`
  잔고는 오너 결정에 따라 `temerosa:guest:nemo` 한 계정으로 합산한다. 이 과정에서 포인트를 만들거나
  버리지 않는다.
- 신규 계정 69개에는 하우스 잔고에서 각 500P를 이전한다. NPC+하우스의 개장 총량은 이전 계약 종가와 같다.

## 에셋

- 별도 팩: `temerosa-series-npcs/0.1.0`
- 116명 중 108명 사용 가능, 8명 unavailable.
- WebP 588개, 팩 전체 약 24.8MB.
- `sm`은 순위·목록, `md`는 좌석 감정, `lg`는 상세 화면용이다.
- 로더는 별도 함수로 지연 로딩한다. 현재 잠긴 1.2 후보 때문에 초기 화면에서 요청하지 않는다.
- 육안 검수는 오너 결정대로 사후 절차이며 `review.html`이 연락판이다.

## 경제 운영값

- 기존 1.1의 과거는 변경하지 않는다. 아래 값은 잠긴 1.2 후보에만 적용한다.
- 신규 계정 개장 자금: 500P, 전액 하우스 내부 이전.
- 명시적 외부 생계 수입 범위의 25배를 카지노 운영 단위로 환산한다. 인물별 반입 비율과 근거는 유지한다.
- 하루 10~14회 방문, 방문당 20~30라운드 범위 안에서 작성 프로필의 상대적 활동성을 유지한다.
- NPC도 플레이어와 같은 10/50/200P, 2~5배 노출을 쓴다.
- PvP는 승패 정산 후 팟의 7.5%를 테이블 수수료로 하우스에 낸다. 분개에는 하우스 상대 계정이 생기므로
  각 라운드 전체 합은 항상 0이다.
- 1.2의 NPC 경기 시간만 플레이어 규모에 맞춰 단축했다. 1.1 시드와 과거 시간축은 그대로다.
