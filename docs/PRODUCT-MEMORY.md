## 우리가 만드는 것

RisuAI 사용자가 사용자 입력과 API 요청을 보낸 뒤 응답을 기다리는 시간에 즐길 수 있는 게임 오락실이다.
커뮤니티에서 알려진 봇카드의 인물·세계관·에셋이 게임에 실제로 들어가므로 일반 웹 미니게임보다 친숙하고
놀라운 경험을 만드는 것이 목표다.

## “사용자에게 봇카드가 필요 없다”의 정확한 뜻

- 게임 제작에는 선정된 봇카드가 필요하다. 파서가 카드와 에셋 모듈을 분해해 콘텐츠팩으로 만든다.
- 완성된 내장 게임을 실행하는 사용자에게는 원본 봇카드 파일이 필요하지 않다.
- 개인 카드 업로드는 계속 지원하지만 제품의 유일한 입구가 아니다.
- 따라서 `봇카드 없이 만든 일반 게임`이 아니라 `봇카드로 제작했지만 바로 실행 가능한 내장 게임`이다.

## 게임 길이에 대한 결정

- 대기 시간용이라는 이유로 모든 게임을 30초·3분에 맞추지 않는다.
- 짧은 놀이, 반복 캐비닛, 10~20분 이상 이어지는 본편을 함께 둔다.
- 핵심 제약은 길이가 아니라 안전한 중단과 빠른 복귀다.
- 응답이 도착했을 때 손해 없이 나갈 수 있고, 다음 방문에 한 번의 선택으로 이어 해야 한다.

## A와 B를 혼동하지 않는다

- A는 여러 세계·여러 장르·여러 플레이 길이를 연결하는 럭키★오락실 제품이다.
- B인 《소녀전선: 잔불 작전》은 첫 대형 캐비닛이자 엔진 기술 검증작이다.
- B가 완성됐다고 A가 완성된 것은 아니다.
- B에서 얻은 콘텐츠 컴파일러, 캐비닛 레지스트리, 결정론 코어 경계, 저장 복구, LittleJS 격리는 A의 공용 자산이다.

## 제품이 실제로 보여야 하는 장면

1. 사용자는 카드 업로드를 요구받지 않고 지금 할 게임을 고른다.
2. 지난 플레이가 있으면 `이어하기`가 첫 행동으로 보인다.
3. 같은 봇카드 세계가 월드컵·짧은 게임·깊은 게임에서 서로 다른 모습으로 재사용된다.
4. 개인 카드를 넣고 싶을 때만 `내 카드로 놀기` 통로를 연다.
5. 게임을 나가도 진행이 보존되고 다른 캐비닛이나 다른 세계를 발견할 수 있다.

- 사용자가 항상 카드를 업로드해야 한다고 가정하지 않는다.
- 모든 카드가 모든 게임을 열어야 한다고 강요하지 않는다.
- 렌더링 엔진을 늘리는 것을 게임 다양성 자체로 착각하지 않는다. 장르 요구와 실측 관문이 있을 때만 추가한다.

  `테메로세 카지노`가 있고, 향후 다른 봇 IP Venue가 옆이나 아래에 추가된다.
- 카지노 내부 무대는 `여백`이다. 여러 시대 외형이 같은 장소에 있을 수 있다는 해석은 `[게임 연결부]`이며,
  워어즈의 하우스·알제의 규정/교환소 배역도 원작 사실로 소급하지 않는다.
- 소녀전선과 개인 카드 삽입은 UI에서 숨기되 코드·저장·유닛 테스트를 보존한다. GFL 에셋 삭제는 보류다.
- 공개 범위는 Venue 선언에서 파생한다. 이어하기는 Venue를 건너뛰고 공개 캐비닛으로 한 번에 복귀한다.
- Phaser는 더비 표현 엔진으로 채택하며 D1의 큰 장면에도 쓴다. 모든 캐비닛에 강제하지 않는다.
  melonJS·Excalibur·LittleJS 더비 렌더러는 Phaser 제품 화면이 같은 기록을 끝까지 재생한 뒤 제거한다.
  LittleJS 자체는 보존된 잔불 작전이 사용하므로 프로젝트 의존성에서 자동 제거하지 않는다.
- 카지노 자산 탐색의 `이름 필터 통과`와 `종횡비 분류`는 승인이나 안전 판정이 아니다. 사람 검수와
  용도별 허용 목록을 통과한 축약 파생본만 배포한다.
- A5의 기존 좌석 대사 72줄은 핵심 인물 연기이므로 뽑기로 다시 잠그지 않는다. 뽑기는 별도 보너스 대사,
  감사된 외형, 유한한 덱·칩 스킨을 쓴다.
- 2026-07-26 오너 결정으로 도둑잡기 마감 다음 공개 게임은 **짝맞추기 기본판**이다. 공개 순서는
  도둑잡기 마감 → Venue → 짝맞추기 → 슬롯 → 인디언 포커 개정이다.
- 짝맞추기의 공개 명칭은 꾸밈말 없는 `짝맞추기`다. 카드 앞면은 승인 이미지 한 장만 표시하고
  인물명·카드명·표정명·툴팁을 게임 및 결과 화면에 노출하지 않는다. 첫 버전은 동일 이미지 두 장을 찾는
  1인 고전 규칙이며 포인트를 발행하지 않는다.
- 슬롯 다음에는 인디언 포커 개정, 관전 예측, Phaser 더비, 빙고를 검토한다. 하이로우·블랙잭·홀덤은
  익숙하지만 테메로세 자산 결합이 얕아 그 뒤다.
- 인디언 포커 0.1은 비공개 시제품이다. `PUBLIC_CABINET_IDS` 한 줄로 공개하지 않고 앤티·베팅·콜·레이즈·폴드,
  공용 판돈 예약/정산, Venue 내부 진입을 갖춘 뒤 공개한다.
- 무료 도둑잡기 순위 보상은 1등 10 P · 2등 5 P · 3등 3 P · 패배 1 P다. 선택 베팅을 해도 함께 지급하고,
  관전에는 지급하지 않는다. 기존 완료 영수증은 다시 지급하지 않는다.
- A16 Venue와 A23 공용 판돈 영수증은 구현됐다. 짝맞추기는 순수 코어와 독립 React 화면까지 구현됐지만
  0.8.0 이미지 허용 목록·저장·전적·Venue 배선 전이므로 아직 공개 캐비닛이 아니다.
- A17 재감사는 5개 CHARX 2,003개를 기록하고 Venue 1·슬롯 16·배경 4 후보를 만들었다. 용도별 육안 승인 전에는
  컴파일러가 공개팩 생성을 거부한다.
