# SPEC-A14 — 뽑기와 수집

> 상태: v1.1 구현 계약 (2026-07-25). **선행: [SPEC-A13](./SPEC-A13-point-economy.md), [SPEC-A17](./SPEC-A17-temerosa-casino-asset-inventory.md).**
>
> 근거: ROADMAP `무료 경제 원칙 > 뽑기 원칙` (2026-07-25 오너 결정).
> A9가 만든 `확정 신규 개봉`을 확률형 뽑기로 확장하고, 뽑을 대상을 넓힌다.

## 1. 왜 확률형이 여기서는 건전한가

가챠가 해로운 이유는 무작위성이 아니라 **현금을 태우게 만들기 때문**이다. 이 프로젝트에는
결제 경로가 없고 서버가 없고 포인트는 플레이로만 나온다. 그 조건에서 뽑기는 **수집 동기와
개봉의 쾌감**만 남는다.

그래서 채택하되, 무료 뽑기가 흔히 망가지는 두 지점을 계약으로 막는다.

- **천장이 없어서 영원히 안 나오는 것** → 확정 천장을 둔다.
- **중복이 쓰레기가 되는 것** → 중복을 다른 값으로 전환한다.

## 2. 무엇을 뽑는가

이미 만들어 둔 자산을 재활용한다. **새 아트를 그리지 않는다.**

| 풀 | 내용물 | 재고 | 생산 비용 |
|---|---|---|---|
| **얼굴** | 승인된 카드 얼굴 이미지 | 카지노용 허용 목록에 들어온 항목 | 파생본 컴파일 필요 |
| **보너스 대사** | 수집용으로 별도 집필·검수한 추가 대사 | 후속 집필분만 | 집필 필요 |
| **덱·칩 스킨** | 승인된 트럼프 뒷면·프레임·칩 조합 | 유한한 선언 목록 | 검수 필요 |
| **테이블** | 승인된 배경 이미지 | 카지노용 허용 목록에 들어온 항목 | 파생본 컴파일 필요 |
| **칭호** | 전적에서 얻는 문구 | 규칙으로 생성 | 0 |

**A5의 기존 72줄은 잠그지 않는다.** 이미 배포된 핵심 인물 연기이며 사건별 후보 수와 쿨다운 계약의 일부다.
이를 사후에 잠그면 수집 상태에 따라 인물이 부자연스럽게 침묵하고 기존 경험이 퇴행한다. 대사를 뽑기에 넣으려면
게임별 핵심 반응과 별개인 보너스 줄을 새로 집필·검수한다.

`PlayingCardBack`이 CSS 변수 기반이어도 임의 색 조합을 무한 재고로 세지 않는다. 이름·팔레트·대비를 검수한
유한한 선언 목록만 풀에 넣는다.

## 3. 레어도 — 발명하지 않는다

ROADMAP의 `earned rarity` 원칙을 그대로 쓰되, 자동 추출 결과는 **후보 등급**이다. 카드 간 중복 제거와
사람의 내용 검수까지 끝난 허용 목록에서만 최종 등급이 된다.

```
흔함    변형이 많은 인물의 기본 표정
보통    변형이 3종 이상인 인물의 감정 표정
드묾    변형이 1~2종뿐인 인물, 고립 로어에 붙은 에셋
특별    조커·마법소녀 네모처럼 명시적으로 단일 세트인 항목
```

- **구조 유래이므로 `카드에 없는 설정을 발명하지 않는다`와 충돌하지 않는다.**
- 개인 카드 파이프라인은 현행 공개 UI 범위 밖이므로 A14 첫 릴리스 풀에 넣지 않는다.
- 등급 산출은 순수 함수이며 `evidence`를 남긴다. 왜 드문지 화면에서 설명할 수 있어야 한다.

## 4. 뽑기 규칙

```
1회      30 P
10연     270 P   (10% 할인, 미보유 1개 확정 포함)
천장     같은 풀에서 20회 안에 미보유 항목이 반드시 나온다
```

- 확률은 **화면에 공개**한다. 숨기지 않는다.
- 천장 카운터는 풀별로 따로 센다. 미보유가 나오면 0으로 돌아간다.
- **잔여 미보유가 0이면 그 풀의 뽑기 버튼이 사라진다.** 빈 뽑기를 팔지 않는다.
- 뽑기 결과는 **시드 결정론**이다. `${walletSeed}:draw:${drawCount}:${poolVersion}` 형태로 재현 가능해야 한다.
- 확률표·천장·보유 추가·포인트 차감·조각 전환은 한 IndexedDB 트랜잭션에서 커밋한다.
- 풀은 불변 `poolVersion`을 가진다. 항목 추가로 과거 영수증의 결과가 바뀌지 않는다.

### 중복 처리

중복이 나오면 **조각**으로 전환한다.

```
흔함 중복   → 조각 1
보통 중복   → 조각 3
드묾 중복   → 조각 8
특별 중복   → 조각 20

조각 40 → 같은 풀에서 원하는 미보유 항목 1개와 교환
```

**중복이 손해가 아니라 확정 획득으로 가는 경로**가 된다. 이것이 무료 뽑기에서 가장 중요한 안전장치다.

### 판수 기반 무료 뽑기

접속이 아니라 **플레이**가 조건이다.

```
완주 5판마다 무료 뽑기 1회 적립. 상한 3회까지 누적.
```

- 시간·날짜를 보지 않는다. 하루에 몰아서 해도 같고, 일주일에 나눠 해도 같다.
- 적립 카운터는 전적(A8)의 완주 기록에서 파생한다. 별도 계수기를 만들지 않는다.

## 5. 개봉 연출

ROADMAP이 명시한 `개봉 연출`이다. **이미 있는 것을 재사용한다.**

- 도둑잡기의 카드 뒤집기 애니메이션(`DrawReveal`)이 그대로 쓰인다.
- 등급에 따라 테두리 광량과 뒤집기 속도만 다르게 한다. 새 파티클 엔진을 넣지 않는다.
- 10연은 한 장씩 뒤집되 **건너뛰기 버튼**을 반드시 둔다.
- `prefers-reduced-motion`에서 연출 없이 결과만 보여 준다.

## 7. 금지사항

1. **현금 결제·환전 경로를 만들지 않는다.**
2. **시간 기반 무료 뽑기를 만들지 않는다.** 판수 기반만 쓴다.
3. **확률을 숨기지 않는다.**
4. **천장 없는 풀을 만들지 않는다.**
5. **중복만 나오는 상태를 만들지 않는다.** 조각 전환이 항상 동작해야 한다.
6. **레어도를 임의로 부여하지 않는다.** 감사된 카드 구조에서 파생하고 근거와 풀 버전을 남긴다.
7. **뽑기 결과가 게임 판정에 영향을 주지 않는다.** 얼굴·대사·스킨은 표현이다.
8. **A5 핵심 대사 72줄을 사후에 잠그지 않는다.** 보너스 대사는 없어도 모든 핵심 사건이 정상 발화해야 한다.
9. **뽑기 화면을 초기 청크에 넣지 않는다.**

## 8. 테스트 관문

1. **천장** — 20회 안에 미보유가 반드시 나온다. 1,000시드 전수.
2. **결정론** — 같은 `(walletSeed, drawCount, pool)`이면 같은 결과다.
3. **잔여 0** — 전부 보유하면 뽑기가 거부되고 포인트가 차감되지 않는다.
4. **중복 전환** — 중복이 등급별 조각으로 정확히 바뀐다.
5. **조각 교환** — 40조각으로 원하는 미보유 항목을 확정 획득한다.
6. **10연 확정** — 10연에 미보유가 최소 1개 포함된다.
7. **적립** — 완주 5판마다 1회가 적립되고 3회에서 멈춘다.
8. **시간 무관** — 적립이 날짜·시각에 영향받지 않는다.
9. **등급 근거** — 모든 등급 판정이 `evidence`를 가진다.
10. **풀 버전** — 항목이 추가된 새 풀에서도 과거 영수증의 결과가 바뀌지 않는다.
11. **핵심 대사 보존** — 수집 상태와 무관하게 A5의 9인×8사건 데이터와 발화 후보가 유지된다.
12. **판정 불변** — 보유 상태를 바꿔도 `resultHash`가 같다.

## 10. 비범위

- **유료 재화·결제.** 영구 금지다.
- **한정 기간 픽업·복각.** 시간 기반이라 접속 강요로 이어진다.
- **강화·합성.** 별도 관문.
- **인물 자체와 핵심 대사를 잠그는 것** — 좌석 인물과 게임 이해에 필요한 반응은 처음부터 전부 열린다.
