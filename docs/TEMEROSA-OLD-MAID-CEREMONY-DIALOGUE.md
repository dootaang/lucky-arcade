## 1. 왜 문서를 나눴나

기존 8상황은 **판이 도는 동안**의 말이고, 여기 다섯은 **판이 열리고 닫히는 순간**의 말이다.
성격이 다르다.

| 축 | 진행 중 8상황 | 의례 5상황 |
|---|---|---|
| 발화 시점 | 무작위·저확률 | **반드시 뜬다** |
| 대상 | 한 명 | `table-open`은 좌석 전원 |
| 실패 시 | 침묵하면 그만 | 침묵하면 판이 밋밋하게 시작·종료 |
| 중복 위험 | 낮음(8줄 풀) | **높음. 한 판에 정확히 한 번씩만 뜬다** |

특히 마지막 항목이 중요하다. 진행 중 대사는 안 뜨면 다른 줄이 뜨지만,
**의례 대사는 그 인물의 그 판 유일한 줄**이다. 한 줄 한 줄이 그 인물의 첫인상이자 마지막 인상이 된다.

## 2. 다섯 상황

```
table-open    배분 직후. 좌석 전원이 한 마디. 이 사람이 이 판에 어떻게 들어오는가
finish-1st    1등으로 손을 비움
finish-2nd    2등
finish-3rd    3등 — 조커가 확정되기 직전에 빠져나온 자리
defeat        조커를 떠안고 패배 확정
```

### 등수마다 감정이 다르다

집필자는 넷을 같은 승리로 쓰지 않는다.

| 상황 | 정서 | 규칙 |
|---|---|---|
| `finish-1st` | **압도** | 그 인물이 가장 자기다운 방식으로 이긴 것 |
| `finish-2nd` | **무난** | 이긴 것도 진 것도 아닌 자리. 남은 둘을 보는 시선이 생긴다 |
| `finish-3rd` | **안도** | 한 끗 차이로 빠져나왔다. **가장 인간적인 자리**이며 균열이 가장 잘 샌다 |
| `defeat` | **확정** | 되돌릴 수 없음 |

`finish-3rd`가 이 세트에서 가장 좋은 자리다. 1등은 자랑하고 2등은 무덤덤하지만,
3등은 방금 죽을 뻔한 사람이다. `guarded` 인물의 겉문장이 여기서 가장 크게 갈라진다.

### `defeat`는 `joker-drawn`과 다른 줄이다

```
joker-drawn   조커를 받았다. 아직 넘길 수 있다.
defeat        조커가 내 것으로 확정됐다. 넘길 곳이 없다.
```

**같은 말을 쓰지 않는다.** `joker-drawn`이 각오라면 `defeat`는 결론이다.
이 구분이 흐려지면 두 줄 중 하나가 죽는다.

### `emptied`와의 관계

`emptied`는 지운다는 뜻이 아니다. **계층이다.**

```
finish-1st/2nd/3rd 가 있으면 → 그것을 쓴다
없으면                        → emptied 로 떨어진다
둘 다 없으면                  → 침묵한다
```

`emptied`는 등수를 모르는 일반형이므로, 등수별 줄이 없는 인물이 추가돼도 판이 조용해지지 않는다.

## 3. 연출 규칙

- **`table-open`을 동시에 띄우지 않는다.** 좌석 순서로 0.4초 간격. 겹치면 아무것도 안 읽힌다.
- **최종 2인 구간의 침묵은 그대로 유지한다.** 조커가 확정되기 **직전**은 여전히 무침묵 구역이고,
  말이 풀리는 것은 결과가 나온 **뒤**다. 이 순서를 뒤집으면 기존 대사집 3절의 낙차 설계가 통째로 무너진다.
- `defeat`는 `despairPortrait`와 함께 띄운다.
- **의례 대사에는 쿨다운을 걸지 않는다.** 판당 한 번뿐이므로 반복 회피 로직의 대상이 아니다.
- 판정에 영향을 주지 않는다. 이 문서를 통째로 비워도 같은 시드의 `resultHash`가 같아야 한다.

# 4. 문안 — 기존 9인

| 상황 | 대사 |
|---|---|

| `finish-1st` | 제일 먼저 다 짝지어 줬네.<br>흩어진 물고기가 한 그물에 모인 기분이야. 비린내는 싫지만. |
| `finish-2nd` | 나도 드디어 끝났거든. 두 번째 도착한 항구라고 해서<br>첫 번째 바다보다 안 아름다운 건 아니잖아. |
| `finish-3rd` | 간신히 다 맞춰서 털어냈네. 마지막 한 쌍은<br>바다가 아니라 팍팍한 맨땅에서 헤엄치는 것만큼 힘들었거든. |
| `defeat` | 결국 내 손에 남았잖아. 짝 없는 불쌍한 카드랑<br>최초의 베스티아라라니, 완전 딴판인데 묘하게 닮았네. |

`defeat`가 페일의 `joker-drawn`("짝이 없는 건 죄가 아니야")의 착지점이다.
짝 없이 태어난 최초의 베스티아가 마지막에 짝 없는 카드와 둘이 남는다. 다섯 줄에는 원문의
**장황함과 무관한 두 대상을 잇는 비유**를 복원했다. 철학만 말하게 하면 페일이 아니라 정돈된 해설자가 된다.

| 상황 | 대사 |
|---|---|

| `finish-1st` | 제가 1등으로 끝냈네요. 신이라면 당연한 결과죠. …아, 근데 나 먼저 가도 되나? |

| `defeat` | 제가 끝까지 들게요. 응답할 자가 마지막 책임도 지니까요. …사실 무서워 죽겠네. |

카노는 최종편의 얼음신 시점을 쓴다. 겉으로는 `~요/~습니다`의 정중하고 침착한 신을 연기하고,
감정이 치솟을 때만 반말의 본심이 샌다. `finish-1st`의 머뭇거림과 `finish-3rd`의 마지막 문장이 그 균열이다.

`defeat`는 **두 박자**로 띄워 두려움과 결심을 분리한다.

## 박니은 — `guarded`

| 상황 | 대사 |
|---|---|
| `table-open` | 착석 완료. 카드 딜링이 세상 멸망보다 꼬이진 않겠지. …안 꼬여야 되는데. |
| `finish-1st` | 1등으로 손패 정리. 역시 정보상의 이름값 하네. …물론 이 의자에서 엉덩이 뗄 생각은 없어. |
| `finish-2nd` | 나도 끝. 적당히 평타쳤네. 난 계속 여기 앉아 있을 테니까 보던 거나 봐. |
| `finish-3rd` | 겨우 털었다. 자리도 못 비우는데 탈출 레이스라니, 내 팔자도 참. |

**정본 보호 규칙 3에 따라 다섯 줄 전부 잔류를 유지한다.** 니은은 손을 비워도 일어나지 않는다.
`finish-3rd`가 특히 좋다 — 나가지도 않을 사람이 나가려고 애쓴 것을 자기가 알아챈다.

`defeat`는 **니은에게만 패배가 손해가 아니다.** 어차피 남을 사람이라 조커를 떠안는 것이 비용이 아니다.
다른 서른넷의 `defeat`와 정서가 근본적으로 다른 유일한 줄이다.

# 5. 문안 — 카지노 26인

## 아데샤 — `guarded`

| 상황 | 대사 |
|---|---|
| `table-open` | 착석. 넷. 개시. |
| `finish-1st` | 최단 시간 완료. 이상 무. |
| `finish-2nd` | 차순 완료. 수순 진행. |
| `finish-3rd` | 완료… 한계선 직전 탈출. |
| `defeat` | 패배 확정. 조커 보유. 내 몫. |

명사만 쓰는 화법을 끝까지 지킨다. **`…` 뒤 한 단어가 아데샤의 유일한 균열**이며,
`finish-3rd`의 "간신히"와 `defeat`의 "내 몫"이 이 인물이 판 전체에서 내놓는 감정의 전부다.

## 안나 나자레아 — `open`

| 상황 | 대사 |
|---|---|
| `table-open` | 다들 앉아! …아니, 앉아 달라고. 명령 아니고 시작하자는 거야. |
| `finish-1st` | 내가 이겼어! …자랑하는 거 아니다? 억울해서 그래. |
| `finish-2nd` | 끝났다. 너 잘하더라. …칭찬이야! 왜 그런 눈으로 봐? |
| `finish-3rd` | 나 나왔어. 위험했다… 너희 걱정한 거야. 나 말고! |
| `defeat` | 내가 쥐고 끝낼게. 됐지? …이러려고 남은 거야, 나 오해하지 마. |

다섯 줄 전부 **말하고 나서 급하게 수습하는** 구조다. 선의가 매번 험하게 나가는 사람의 리듬이며,
수습하는 쪽이 진심이다.

## 아폴리온 아이테 — `guarded`

| 상황 | 대사 |
|---|---|

| 상황 | 대사 |
|---|---|
| `table-open` | 참가자 4인 확인. 통계적으로 3인은 안도 범위 내. |
| `finish-1st` | 최단 시간 탈출 완료. 극히 드문 변수이자 예외. |
| `finish-2nd` | 2위로 종료. 예상 수치 범위 내 정상 결과. |
| `finish-3rd` | 최하위 직전 안전권 진입. …체온 저하 멈춤 확인. |
| `defeat` | 최종 잔류 확정. 누군가는 비극을 맡을 예정. …본인으로 처리. |

죽음을 필연으로 말하면서 실은 지키려는 사람이다. `defeat`의 `…` 뒤에서 그 본심이 처음 드러나고,
`finish-3rd`의 "생각보다"는 자기가 안심할 줄 몰랐다는 뜻이다.

## 레이븐 — `bluffer`

| 상황 | 대사 |
|---|---|
| `table-open` | 좋은 판이 되길 바랍니다. 정산은 제가 맡겠습니다. |
| `finish-1st` | 가장 먼저 청산했습니다. 좋은 거래였습니다. |
| `finish-2nd` | 차순위로 마무리했습니다. 손해는 아닌 자리입니다. |
| `finish-3rd` | 아슬아슬하게 흑자 전환입니다. 다행입니다. |
| `defeat` | 제 쪽 손실로 처리하겠습니다. 단가는 기억하겠습니다. |

어떤 상황에서도 정중함이 무너지지 않는다. `defeat`에서도 존댓말이 그대로이고,
**`…` 뒤가 위협이 아니라 장부**다. 카지노 환전소와 가장 잘 어울리는 인물이다.

## 테뮤테 — `open`

| 상황 | 대사 |
|---|---|
| `table-open` | 자, 시작하자. 다들 다치지 말고… 내가 또 잔소리하네. |
| `finish-1st` | 하아, 내가 1등이네. 어른이 애들 사이에 끼어서 참 잘하는 짓이다. |
| `finish-2nd` | 2등으로 털었네. 안 튀고 적당히 빠지는 게 오래 사는 길이야. |
| `finish-3rd` | 겨우 빠져나왔네. …야, 너 괜찮냐? 패 똑바로 쥐고 있어. |
| `defeat` | 하아… 줘 봐, 내가 들고 있을게. 액땜은 어른이 해야지. |

이상을 잃고 실무로 버티는 사람인데 **잔소리는 못 버린다.** `table-open`에서 스스로 그걸 알아채고,
`finish-3rd`에서 자기가 빠져나온 직후 남은 사람을 걱정한다.

튜밋튜가 같은 테이블에 있으면 층이 두꺼워진다. 남매라는 말은 한 줄도 하지 않는다.

## 트레버 — `guarded`

| 상황 | 대사 |
|---|---|
| `table-open` | 적당히 하자고. 욕심내서 선 넘으면 사단 나. |
| `finish-1st` | 1등으로 막차 탔네. …나 같은 놈도 되긴 되는구나. |
| `finish-2nd` | 2등 도착. 딱 내 분수에 맞는 승강장이야. 만족해. |
| `finish-3rd` | 겨우 빠져나왔네. 종착역 직전에 내리면 그걸로 충분해. |
| `defeat` | 역시나. …분수껏 지켰는데 왜 하필 나한테 꽂혀. |

**`finish-1st`이 트레버의 유일한 균열**이다. `분수껏`을 신조로 삼은 사람이 실제로 1등을 하자
신조가 아니라 체념이었다는 게 드러난다. `finish-2nd`의 반복("만족해 … 만족한다니까")은 자기 설득이다.

## 땡칠이 — `open`

| 상황 | 대사 |
|---|---|
| `table-open` | 다 모였다! 판 벌이자! 좋다! 좋아! |
| `finish-1st` | 1등이다! 멍멍! 아, 미안! 털었다! |
| `finish-2nd` | 2등이다! 이것도 엄청 좋은 거지! |
| `finish-3rd` | 살았다! 무서웠어! 진짜 쫄았다! |
| `defeat` | 아… 나다. 내 손에 남았어. 괜찮아. 내가 하면 돼. |

**`defeat`에서 느낌표가 사라지고 짖음도 멈춘다.** 네 줄 내내 소리치던 인물이 조용해지는 것만으로
무게가 생긴다. 어휘를 무겁게 만들지 않고 문장부호만 바꾼다.

## 튜밋튜 — `open`

| 상황 | 대사 |
|---|---|
| `table-open` | 자, 드디어 개전이에요! E랭크 헌터의 저력을 보여 드릴게요! |
| `finish-1st` | 1등 도착!! 봤죠?! 봤죠?! 이게 바로 E랭크의 힘이에요! |
| `finish-2nd` | 2등으로 골인이에요! E랭크 치고는 공적 대단한 거 아닙니까?! |
| `finish-3rd` | 아우, 살았다! E랭크는 원래 생존력 하나로 버티는 거거든요! |
| `defeat` | 말도 안 돼… 이거 완전 S랭크 난이도잖아요! 제 등급 오버거든요! |

키케로와 둘 다 등급을 말하지만 방향이 반대다. **키케로는 등급으로 자기를 방어하고 튜밋튜는 자랑한다.**
자기만의 등급표라 `E랭크`가 최고 등급이라는 사실을 아무에게도 설명하지 않는다.

## 율 — `standard`

| 상황 | 대사 |
|---|---|
| `table-open` | 어, 시작이에요? 저 뭐 하러 앉았더라… 아, 카드게임! |
| `finish-1st` | 끝났어요? 제가요? 언제 다 버렸지… 아무튼 이겼네요! |
| `finish-2nd` | 두 번째네요. …어라, 뭐가 두 번째였죠? 아, 저요? |
| `finish-3rd` | 빠져나왔다… 나왔죠? 맞다고 해 주세요. |
| `defeat` | 내 손에 이게 왜 있지… 아, 아까 그거구나. …근데 언제 들어왔더라? |

전투는 유능하고 생활은 파국인 사람이다. **자기가 이긴 것도 나중에 안다.**
디아모와 함께 `standard` 둘인데 겹치지 않는다 — 디아모는 남의 기억이라 흐릿하고 율은 자기 기억이 흐릿하다.

## 6. 교차 장치

기존 대사집 6절과 같은 방식이다. **전용 대사를 새로 만들지 않고** 기존 줄이 나란히 뜨는 것만으로 성립한다.
구현에서 조합 조건을 넣을 필요가 없다.

| 조합 | 장치 |
|---|---|
| 크레이들 + 김덕배 | 두 `defeat`가 같은 말이다. "젊은 것들 손에 있을 물건이 아니야" / "초보한테 넘길 물건이 아니야". 한 명은 외치고 한 명은 줄인다. |
| 에스더 + 노스탤지아 | 둘 다 조커를 "안는다"고 한다. 한쪽은 죽음이 자비라서, 한쪽은 보호가 신앙이라서. |
| 키케로 + 튜밋튜 | 등급 어휘가 같은 테이블에 앉는다. 한쪽은 방어, 한쪽은 자랑. |
| 테뮤테 + 튜밋튜 | 테뮤테의 `finish-3rd`("야, 너 괜찮냐")가 튜밋튜의 `defeat` 직전에 뜨면 남매라는 말 없이 성립한다. |
| 아데샤 + 크레바 | 명사만 쓰는 둘이 나란히 앉으면 어휘 길이가 같고 온도가 다르다. 관측 보고와 임무 보고. |
| 박니은 단독 | 서른네 명의 `finish-*`가 전부 퇴장인데 니은만 잔류다. `defeat`조차 손해가 아니다. |
| 카노 + 크레이들 | 둘 다 `finish-1st`을 민망해한다. 남을 구하는 것이 목적인 사람에게 먼저 나가는 건 실패다. |

## 7. 집필 시 지킨 것

1. **`defeat`와 `joker-drawn`을 다른 줄로 썼다.** 각오와 결론은 다르다.
2. **등수 넷을 같은 승리로 쓰지 않았다.** 압도 · 무난 · 안도 · 확정.
3. **`finish-3rd`에 균열을 몰았다.** 방금 죽을 뻔한 사람의 자리다.
4. **정본 보호 규칙 6조를 전부 지켰다.** 특히 박니은은 다섯 줄 전부 잔류이고,
   리엘·네모·바치칼의 정체와 동일성은 한 글자도 흘리지 않았다.
5. **성인·폭력 묘사를 넣지 않았다.** 카미유·에스더·크레바는 카드 게임 어휘로만 표현했다.
6. **`standard` 둘(디아모·율)도 고유한 목소리를 받았다.** 명부 5절의 결정을 따른다.
7. **웃기려 하지 않았다.** 유머는 전부 격조와 판돈의 낙차에서만 나온다.

## 8. 배선 시 지킬 것

1. **문안을 코드에서 고치지 않는다.** 수정은 이 문서에서 하고 데이터로 반영한다.
2. **문안이 없는 인물은 침묵한다.** 없는 줄을 생성하지 않는다.
3. `finish-*`가 없으면 `emptied`로, 그것도 없으면 침묵으로 떨어진다.
4. **네모의 `defeat`는 두 박자**다. `<br>`을 한 말풍선으로 합치지 않는다.
5. 최종 2인 구간 침묵을 유지한다. 말이 풀리는 것은 결과가 나온 뒤다.
6. 이 문서를 통째로 비워도 같은 시드의 `resultHash`가 같아야 한다.
