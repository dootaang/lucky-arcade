# SPEC-A26 — 살아 있는 카지노 NPC 원장 0.7

> 상태: 구현 계약 (2026-07-29). 0.6의 실제 대국·순위 보상 원장을 계승한다.

## 변경 이유

NPC도 도둑잡기에서 플레이어와 같은 방식으로 선택 베팅한다. 대국 참가자는 자기 우승에만 걸 수 있고,
대국에 참가하지 않은 NPC는 관전석에서 우승자 또는 최종 조커 보유자를 예측한다. 선택과 결과는 모두
UTC 시각·계약·시드의 순수 함수이며 서버나 숨은 실시간 프로세스를 만들지 않는다.

## 베팅 계약

- 참가자는 베팅하지 않고 무료 순위 보상만 받을 수 있다. 베팅할 경우 대상은 자기 자신, 시장은
  `first-place`로 고정한다.
- 비참가 관전자는 한 대국에서 최대 1명만 참여한다. `first-place`와 `joker-holder` 중 하나를 고르고,
  해당 시장에서 한 인물만 예측한다.
- 참가자·관전자 모두 판돈 `10 / 50 / 200 P`, 배율 `2 / 3 / 4 / 5배`를 쓴다. 최대 손실은
  `판돈 × 배율`이며 적중하면 같은 금액만큼 순이익, 실패하면 같은 금액만큼 손실이다.
- 잔액과 성격별 최대 노출 범위를 넘는 선택은 만들지 않는다. 베팅하지 못해도 무료 도둑잡기 참가와
  순위 보상은 유지한다.
- 베팅 선택 시드와 대국 결과 시드를 분리한다. 대상 선택 함수는 결과·손패·조커 보유자를 입력받지 않는다.
  관전자의 예측은 공개된 NPC별 도둑잡기 실력과 관전자 자신의 분석 오차만 사용한다.

## 좌석·표시 계약

- 관전 베팅 중인 NPC는 `spectating` 프레즌스로 표시하며 해당 대국이 끝날 때까지 플레이어가 상대 NPC로
  선택할 수 없다.
- LIVE PLAY TAPE에는 베팅 대상, `우승 예측` 또는 `꼴찌 예측`, 판돈과 배율을 표시한다.
- 최근 정산은 순위 보상과 예측 베팅을 별도 행으로 표시한다. 같은 참가자가 순위 보상으로 이득을 보고
  자기 예측에는 실패했더라도 초록 합산 행 하나로 뭉개지 않는다.
- 예측 적중은 초록, 실패는 빨강이다. 원장 잔고 합계는 분리 전 실제 세션의 합계와 정확히 일치해야 한다.

## 버전·복구 계약

- 원장 계약은 `npc-ledger/0.7`, 라이브 테이프는 `npc-live-tape/0.3`, 실제 정산은
  `npc-live-rounds/0.5`를 쓴다.
- 체크포인트 키도 `npc-ledger/0.7`로 분리한다. 이전 체크포인트를 새 과거에 섞지 않고 기준일부터
  전량 재계산한다.
- 예측 원장과 유저 지갑은 분리한다. NPC 베팅은 유저 포인트를 읽거나 쓰지 않는다.

## 검증 관문

1. 참가자 베팅은 항상 자기 자신·우승 시장이다.
2. 관전자는 참가자와 겹치지 않고 우승·최종 조커 두 시장을 모두 사용한다.
3. 예약액은 판돈×배율이고 적중·실패 손익은 정확히 `+예약액 / -예약액`이다.
4. 베팅 선택·결과 시드 영역이 분리되고 동일 입력은 같은 원장을 만든다.
5. 관전자는 베팅 시간 동안 상대 선택에서 잠긴다.
6. 생산 프로필 365일 경제는 0.6의 관문을 유지한다. 1,000일 관측값도 별도로 기록해 장기 집중을 감시한다.

## 장기 관측 기준선

구현 시점의 생산 프로필 1,000일 결정론 시뮬레이션은 자기 베팅 106,216건, 관전 베팅 47,581건,
적중 50,533건, 실패 103,264건이었다. 최종 총잔고 110,905 P, 중앙값 70 P, 최고 60,225 P,
1위 점유율 54.3%다. 이는 현행 60% 안전선 안이지만 장기 집중도가 높은 편이다. 이후 조정이 필요하면
같은 계약의 상수를 몰래 바꾸지 않고 새 계약과 기준선을 만든다.
