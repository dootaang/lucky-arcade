## 1. 집필 근거

기존 9인은 스토리 정본에서 해석을 끌어왔지만, 신규 26명은 **카드가 화법을 직접 적어 두었다.**
각 인물 시트에 `Speaking style` 필드가 있다.

```
아데샤    Extremely terse, often only nouns
에코      Third person · Compulsively narrates all actions/feelings/thoughts
카미유    Unnaturally drawn sentence endings · Low, purring tone
```

**그래서 화법은 발명하지 않는다.** 카드가 정한 말투를 지키고, 그 말투로 카드 게임 상황을 말하게 한다.
집필의 창작 몫은 `무엇을 말하는가`이지 `어떻게 말하는가`가 아니다.

## 2. `standard` 화법 규칙 (2026-07-26 오너 결정)

기존 세 성격에 네 번째를 더한다.

| tellStyle | 화법 규칙 |
|---|---|
| `open` | 말이 곧 상태다. 숨기지 않고 수습하지 않는다 |
| `guarded` | 겉문장을 먼저 말하고 `…` 뒤에 진심이 한 조각 샌다 |
| `bluffer` | 거짓말하지 않는다. 상황을 자기 프레임으로 재정의한다 |
| **`standard`** | **전략적으로 숨기거나 뒤집지 않는다. 그러나 목소리는 반드시 창작한다** |

**`standard`를 밋밋함의 동의어로 쓰지 않는다.** 속임 전략이 없을 뿐이며, 인물 해석에서 끌어낸
고유한 목소리를 그대로 부여한다. 율의 산만함, 디아모의 몽유는 전략이 아니라 그 사람 자체다.

## 5. 1차 8명 문안

목소리가 서로 겹치지 않고 기존 9인과도 겹치지 않는 여덟이다.

### 에코 — `open`

> 사고를 언어화하는 정신증을 안고 있다. 생각이 자동으로 입 밖으로 나온다.
> 숨기는 것이 성격이 아니라 **물리적으로 불가능하다.** 그것이 고문의 결과다.

| 상황 | 대사 |
|---|---|
| `watching` | 에코는 기다리고 있어. 기다리는 게 지루하다고 에코는 생각해. 방금 그 생각도 말해 버렸어. |
| `idle-draw` | 에코가 한 장 가져왔어. 별로였다고 에코는 느꼈어. |
| `pair-discard` | 두 장이 맞았어. 에코는 기쁘다고 말하고 있어. |
| `taken-from` | 누가 에코 손에서 가져갔어. 에코는 막을 생각을 안 했어. |
| `pair-made` | 맞췄어. 에코는 이걸 운이라고 생각해. |
| `joker-drawn` | 조커야. 에코는 지금 당황했다고 말해야 해. |
| `joker-left` | 갔어. 에코는 안심했어. 숨길 수가 없어서 미안해. |
| `emptied` | 에코는 끝났어. 에코가 무슨 생각을 했는지 다들 알았을 거야. 늘 그래. |

`joker-drawn`의 `말해야 해`가 핵심이다. 당황을 표현하는 게 아니라 **당황했다는 사실을 발화해야만 하는 강박**이다.
`emptied`는 숨길 수 없는 삶 전체를 한 줄로 접는다. 도둑잡기에서 이 인물은 **구조적으로 최악의 플레이어**다.

### 아데샤 — `guarded`

> 감정을 지우고 만들어진 실험체. 자기를 거둔 사람의 지시만 따른다. 대의에는 관심이 없다.
> 말을 아끼는 것이 아니라 **말할 것이 없다.**

| 상황 | 대사 |
|---|---|
| `watching` | 대기. |
| `idle-draw` | 한 장. 무의미. |
| `pair-discard` | 정리. |
| `taken-from` | 가져갔음. 문제없음. |
| `pair-made` | 일치. |
| `joker-drawn` | …이물질. |
| `joker-left` | 이관 완료. |
| `emptied` | 임무 종료. …다음 지시. |

여덟 줄 합쳐 서른 자가 안 된다. **기존 아홉 명 중 누구와도 겹치지 않는 유일한 극단**이다.
`joker-drawn`에서 조커를 카드가 아니라 `이물질`로 부른다. `emptied`의 `다음 지시`는
지시가 없으면 존재할 이유가 없는 사람의 한 줄이다.

### 땡칠이 — `open`

> 108세인데 어린아이처럼 단순하다. 반짝이는 것을 모으고 볕에서 잔다.
> 좋아하는 사람을 따라다니는 것이 삶의 전부다.

| 상황 | 대사 |
|---|---|
| `watching` | 다들 조용하네. 나 여기 있어. |
| `idle-draw` | 가져왔다! 어, 이거 아니네. |
| `pair-discard` | 둘 똑같아! 버려! |
| `taken-from` | 가져가도 돼. 나 많아. |
| `pair-made` | 맞았다! 맞았어! 봤어? |
| `joker-drawn` | …이거 반짝이지도 않네. |
| `joker-left` | 가져갔다. 잘 가. |
| `emptied` | 다 없어졌어. 이제 뭐 해? 나 여기 있어도 돼? |

`joker-drawn`이 반짝이는 것을 모으는 습성과 만난다. 조커가 무서운 게 아니라 **예쁘지 않아서** 실망한다.
`emptied`는 다른 인물들과 정반대다 — 손을 비우고도 **떠나기 싫어한다.**

### 카미유 — `bluffer`

> 죽이기보다 가지고 노는 쪽을 택한다. 목적은 결과가 아니라 **반응의 수집**이다.

| 상황 | 대사 |
|---|---|
| `watching` | 다들 무슨 얼굴을 하고 있는지…… 그게 제일 재밌는 부분이거든요오. |
| `idle-draw` | 한 장…… 시시하네에. 아무 반응도 안 나왔잖아요오. |
| `pair-discard` | 짝을 맞췄어요오. 이런 건 금방 끝나서 아쉬워어. |
| `taken-from` | 가져가세요오. 어떤 표정을 지을지 보고 싶으니까아. |
| `pair-made` | 어라. 벌써 맞았네에. 좀 더 헤매 주지이. |
| `joker-drawn` | ……이건 제 취향이 아닌데에. |
| `joker-left` | 잘 받으셨나요오. 천천히 즐기세요오. |
| `emptied` | 다 끝났네요오. 아무도 제 얼굴은 안 봤죠오? |

`taken-from`이 이 인물의 존재론이다 — 카드를 아까워하지 않고 **뽑는 사람의 표정을 기다린다.**
`emptied`는 반응을 수집하던 자가 **아무에게도 관찰되지 않았다**는 것을 깨닫는 줄이다.

### 레이븐 — `bluffer`

> 모든 것에 값을 매긴다. 돈은 힘이자 보호의 상징이다.
> 값을 매길 수 없는 것이 딱 하나 있고, 그것 때문에 이 모든 걸 하고 있다.

| 상황 | 대사 |
|---|---|
| `watching` | 진행 상황을 지켜보겠습니다. 관전도 서비스의 일부니까요. |
| `idle-draw` | 한 장 수령했습니다. 장부에 반영하겠습니다. |
| `pair-discard` | 결제 완료. 두 장을 정산했습니다. |
| `taken-from` | 가져가십시오. 재고는 다시 채우면 됩니다. |
| `pair-made` | 예상 수익 범위 안입니다. |
| `joker-drawn` | ……이건 값을 매길 수가 없군요. |
| `joker-left` | 양도 완료했습니다. 반품은 받지 않습니다. |
| `emptied` | 정산이 끝났습니다. 남은 건…… 돈으로 살 수 없는 것뿐이네요. |

알제와 어휘군이 겹치지만 성격이 다르다. **알제는 책임을 밀어내는 공문서, 레이븐은 값을 매기는 장부**다.
`joker-drawn`과 `emptied`가 짝을 이룬다 — 값을 못 매기는 것이 이 사람의 유일한 약점이다.
카지노 환전소 배역에 그대로 쓸 수 있다.

### 김덕배 — `guarded`

> 능력 없이 검술만으로 한 세기를 버텼다. 복수를 찾다 답을 찾는 것으로 바뀌었고,
> 이제는 못 찾을 것을 반쯤 알고 있다.

| 상황 | 대사 |
|---|---|
| `watching` | …예전엔 이런 판을 다르게 불렀지. 이름은 잊었군. |
| `idle-draw` | 한 장. …이런 게 쌓여서 백 년이 됐지. |
| `pair-discard` | 맞는 것끼리는 결국 만나더군. |
| `taken-from` | 가져가게. 쥐고 있어 봐야 무거워질 뿐이야. |
| `pair-made` | …운이군. 실력이라고 해 둘 나이는 지났어. |
| `joker-drawn` | …이런 건 예전에도 있었지. 이름만 달랐고. |
| `joker-left` | 넘겼군. …누구 손에 있든 그건 그대로야. |
| `emptied` | 나는 여기까지야. …결국 아무것도 못 알아냈군. |

`emptied`가 138년의 결론이다. 카드 게임 한 판이 그 사람의 생애를 그대로 요약한다.
워어즈와 톤이 겹칠 위험이 있으나, **워어즈는 되돌리지 않기로 한 자이고 김덕배는 못 찾은 자**다.

### 모르시사 — `open`

> 가장 약한 정예. `샌드백`이라 불린다. 영웅을 꿈꿨던 것을 지금은 숨긴다.
> 자기를 낮추는 것이 방어다.

| 상황 | 대사 |
|---|---|
| `watching` | 저, 저는 그냥… 보고 있을게요. 방해 안 되게. |
| `idle-draw` | 아, 하나… 가져왔습니다. 죄송합니다. |
| `pair-discard` | 마, 맞았네요. 이런 건 가끔… 되기도 하더라고요. |
| `taken-from` | 가, 가져가세요. 어차피 제 건 별로… |
| `pair-made` | 어… 됐다. 됐어요. 아무한테도 말 안 할게요. |
| `joker-drawn` | 역시… 저한테 오네요. 늘 이래요. |
| `joker-left` | 가, 갔어요. 미안해요. 정말 미안해요. |
| `emptied` | 저… 끝났어요. 이번엔 아무한테도 폐 안 끼쳤죠? |

`idle-draw`에서 카드를 뽑고 사과한다. `pair-made`에서는 잘한 것을 숨긴다.
`joker-left`는 조커를 넘기고 **남에게 사과**한다 — 이 게임에서 유일하다.
`emptied`는 존재 자체를 폐로 여기는 사람의 한 줄이다.

### 율 — `standard`

> 전투는 최고이고 생활은 파국이다. 부엌을 다섯 번 태웠고 장비를 스물여덟 개 망쳤고
> 약속을 이백쉰여섯 번 잊었다. 본인은 크게 신경 쓰지 않는다.

| 상황 | 대사 |
|---|---|
| `watching` | 어… 지금 누구 차례였죠? |
| `idle-draw` | 한 장 뽑았고… 어, 이거 왜 뽑았더라. |
| `pair-discard` | 이거랑 이거랑 같네요. 버리면… 버리는 거 맞죠? |
| `taken-from` | 가져가세요. 어차피 뭐가 있었는지 기억 안 나요. |
| `pair-made` | 어? 맞았네. 노린 건 아닌데. |
| `joker-drawn` | 이건… 아, 이거 그거죠. 그… 나쁜 거. |
| `joker-left` | 넘겼나요? 넘겼구나. 다행이다. |
| `emptied` | 다 없어졌네요. 제가 뭘 했는지는 모르겠는데, 잘 됐나 봐요. |

`taken-from`이 이 인물이 `standard`인 이유를 그대로 설명한다 —
**기억하지 못해서 결과적으로 완벽한 포커페이스가 된다.** 감추려는 의지가 없는데 아무것도 새지 않는다.

## 6. 2차 18명 문안 — 핵심 5상황

`watching · idle-draw · taken-from · pair-discard · emptied`.
앞의 넷은 발화 확률이 높아 실제로 보이고, `emptied`는 인물이 착지하는 줄이다.

### 안나 나자레아 — `open`

> 선의가 매번 험하게 전달된다. 가시 면류관을 아프면서도 벗지 않는다.

| 상황 | 대사 |
|---|---|
| `watching` | 다들 편하게 해. …아니, 명령 아니야. 부탁이야. |
| `idle-draw` | 한 장 받았다. …고맙다는 뜻이야. |
| `taken-from` | 가져가. 노려보는 거 아니야. 원래 눈이 이래. |
| `pair-discard` | 정리했다. 잘한 거 맞지? …맞다고 해 줘. |
| `emptied` | 먼저 빠진다. …다들 잘하고 있어. 진심이야. 표정이 문제지. |

### 아폴리온 아이테 — `guarded`

> 376년째 무기력하다. 증오조차 피곤해서 하지 않는다. 문장 중간에 한숨이 든다.

| 상황 | 대사 |
|---|---|
| `watching` | …아직인가. …하아. |
| `idle-draw` | 한 장. …굳이 봐야 하나. |
| `taken-from` | 가져가. 말리는 것도 일이라. |
| `pair-discard` | 둘. 버렸다. …끝. |
| `emptied` | 끝났군. …삼백 년 넘게, 뭐든 이렇게 끝나더라. |

### 브체 — `open`

> 스무 살, 월세 석 달 밀림. 궁지에서 `상태창`을 중얼거리며 버틴다.

| 상황 | 대사 |
|---|---|
| `watching` | 남 노는 거 구경하는 게 제일 싸게 먹히지. |
| `idle-draw` | 한 장 획득. …획득 아이템, 쓰레기. |
| `taken-from` | 가져가라. 어차피 내 건 원래 없었어. |
| `pair-discard` | 두 장 소모. 인벤토리 정리 완료. |
| `emptied` | 다 털었다. 이번 달 방세는… 아, 이건 돈 안 되지. |

### 키케로 — `guarded`

> 등급 하나로 자존을 지탱한다. 지갑에는 죽은 아이의 사진이 있다.

| 상황 | 대사 |
|---|---|
| `watching` | 지켜보고 있습니다. 1급쯤 되면 보는 것도 일이라. |
| `idle-draw` | 한 장 수령. 이 정도 배분은 계산 안에 있었습니다. |
| `taken-from` | 가져가시죠. 하급자에게 양보하는 것도 등급의 의무니까. |
| `pair-discard` | 정리했습니다. 효율이란 이런 겁니다. |

## 7. 2차에서 드러난 관계망

전용 대사를 새로 만들지 않고 **기존 줄이 나란히 뜨는 것만으로** 성립한다. 대사집 6절의 교차 장치와 같은 방식이다.

| 조합 | 장치 |
|---|---|
| **튜밋튜 · 테뮤테 · 카트린카** | 튜밋튜의 `emptied`가 `누나한테 자랑해야지`이고, 테뮤테의 `emptied`가 `야, 너 조심해`다. 카트린카는 그를 백 번 살리고 한 번도 공짜로 해주지 않았는데 `emptied`에서 `장부에 안 적은 게 하나 있는데`라고 한다. **셋이 앉으면 한 가족이 된다.** |
| **노스탤지아 · 에스더** | 노스탤지아가 트라이곤의 지도자이고 에스더가 그 조직의 처형자다. 둘의 `pair-discard`가 나란히 뜨면 같은 교리의 두 얼굴이 된다 — `구원이란 덜어 내는 일`과 `편안해 보이지 않나요`. |
| **폐어 · 크레이들** | 신참을 대하는 정반대의 방식. 한쪽은 죽는다고 말하며 명단을 적고, 한쪽은 살린다고 외치며 앞장선다. |
| **모르시사 · 레빌로트** | 1차의 모르시사는 레빌로트에게 놀림받으면서도 지지받는 사이다. |
