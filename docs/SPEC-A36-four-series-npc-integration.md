# SPEC-A36 — 테메로세 4시리즈 전수 NPC 편입

> 상태: 1단계 신원 명부와 기존 계정 승계표 구현 완료. 런타임 전환은 인물별 성격·경제 프로필과 배포 초상이 준비된 묶음부터 진행한다.
>
> 정본 입력: 서곡√2, 테메로세√2, 베스티아화, 피날레 CHARX 네 파일. 독립 `Nemo.charx`의 마법소녀 네모는 기존 특별 출전자로 보존하지만 네 시리즈 집계에는 넣지 않는다.

## 1. 신원 단위

NPC는 생물학적 개인이 아니라 **`(시리즈, 작품 안에서 별도로 제시된 인격)`**으로 식별한다.

```text
temerosa:overture:pale
temerosa:root2:pale
temerosa:finale:pale
```

동일 인물이어도 시리즈가 다르면 잔고·전적·성격·대사가 서로 다른 NPC다. 한 작품 안에서도 별도 이름과 이미지 묶음으로 제시된 인격은 나눈다. 예를 들어 베스티아화의 라일라와 리엘은 `canonicalPersonKey: "lyla"`로 관계만 연결하고 계정은 합치지 않는다.

반대로 같은 인격의 표정·의상·동일 파일 재수록은 새 NPC가 아니다. `canonicalPersonKey`는 탐색과 관계 표시 전용이며 경제나 게임 상태의 키로 쓰지 않는다.

## 2. 전수 조사 결과

`pnpm content:temerosa:series:npcs`가 로어 인물 구역과 안전한 감정 이미지 묶음의 합집합을 만든다.

| 시리즈 | 로어 근거 인격 | 이미지 전용 후보 | 합계 |
|---|---:|---:|---:|
| 서곡 | 12 | 0 | 12 |
| √2 | 18 | 0 | 18 |
| 베스티아화 | 53 | 4 | 57 |
| 피날레 | 29 | 0 | 29 |
| **합계** | **112** | **4** | **116** |

이미지 전용 네 항목은 `Riel`, `Nieun Pluto`, `Female`, `Male`이다. 앞의 둘은 별도 출전 인격으로 유지한다. `Female`과 `Male`은 구현 후 검수 대상이며, 틀린 이름이라고 확인되더라도 조용히 삭제하지 않고 명부 상태와 교정 근거를 남긴다.

안전 이름 정책을 통과한 감정 이미지 후보는 1,616개다. 116명 중 108명에게 최소 한 장이 있고, 95명은 `neutral/pleased/tense/despair` 네 역할을 실제 감정 자산만으로 바로 구성할 수 있다. 13명은 부분 폴백 검토가 필요하고 8명은 로어에는 있으나 좌석 초상이 없다. 초상 부재는 원장 편입을 막지 않지만 게임 좌석 편입은 막는다.

생성 명부는 [TEMEROSA-SERIES-NPC-ROSTER.md](./TEMEROSA-SERIES-NPC-ROSTER.md)다. 런타임용 JSON에는 CHARX 본문을 넣지 않고 로어 항목 번호·키·본문 SHA-256·자산 경로만 저장한다.

## 3. 기존 34인 승계

기존 계정 하나는 정확히 하나의 시리즈 계정으로만 이어진다. 같은 인물의 모든 시대에 기존 잔고를 복제하면 포인트가 새로 생기므로 금지한다.

승계표는 `cabinets/casino-ledger/src/temerosa-series-migration.ts`에 동결한다.

- 기존 피날레 초상을 쓰던 페일·카노·바치칼·알제·니은은 피날레 계정으로 이어진다.
- 라일라·리엘과 기존 베스티아화 로스터는 베스티아화 계정으로 이어진다.
- 기존 마법소녀 네모는 `temerosa:guest:nemo`로 유지한다.
- 과거 영수증의 ID를 다시 쓰지 않는다. 표시 해석만 후계 ID를 이용한다.
- 워어즈의 시리즈별 인격은 명부에 존재하지만 `house` 역할이며 개인 순위·최근 정산에서 제외한다.

## 4. 편입 수준

116명을 한 번에 현재 34명과 같은 대사 밀도로 만들면 검수가 무너진다. 완성도를 낮추는 대신 기능 층을 분리한다.

| 수준 | 필수 데이터 | 허용 기능 |
|---|---|---|
| A — 카지노 주민 | 신원, 시리즈, 경제 프로필 | 원장·순위·최근 활동·라이브 테이프 |
| B — 게임 상대 | A + 좌석 초상 + 게임별 성격·실력 | 대국·관전 좌석·감정 반응 |
| C — 발화 상대 | B + 화법 계약 + 검수된 게임별 대사 | 말풍선·시작·결과 대사 |

최종 목표는 전원 C다. 다만 C가 준비되지 않은 NPC에게 공통 대사나 자동 생성 문안을 붙이지 않는다. 검수 전에는 침묵하는 것이 정본에 없는 성격을 발명하는 것보다 낫다.

## 5. 배치 순서

1. 베스티아화: 기존 26명 자료가 있어 새 ID·에셋·원장 전환을 검증하기 가장 쉽다.
2. 피날레: 기존 기본 좌석 5명과 연결되는 승계를 완료한다.
3. √2
4. 서곡

각 배치는 8~12명 단위로 신원 근거 → 안전 이미지 → 성격·경제 → 대사 순으로 닫는다. 인물의 중요도로 누락시키지 않는다.

## 6. 에셋 규칙

- 자산 ID와 경로에 시리즈와 출전 인격을 넣는다.
- 다른 시리즈 초상으로 부족한 표정을 메우지 않는다.
- `neutral`은 실제 자산이 필수다. 나머지 표정 대체는 실제 사용한 감정과 `fallbackFrom`을 기록한다.
- 원본보다 큰 파생본을 만들지 않는다.
- 자동 선구현 후 오너 갤러리에서 사후 검수한다.
- 원본 CHARX·원본 추출물·금지 상태 이미지는 커밋하지 않는다.

## 7. 런타임 전환 관문

시리즈 ID를 실제 원장과 게임 좌석의 기본 키로 바꾸려면 다음이 모두 필요하다.

1. 기존 34인 후계 대상이 정확히 하나이며 중복 대상이 없다.
2. 배치에 들어오는 모든 신규 NPC가 독립 경제 프로필을 갖는다.
3. 새 계약 기준일은 KST 자정으로 고정한다.
4. 기존 잔고는 후계 계정 한 곳으로만 이동하고 신규 시대 계정에는 복제하지 않는다.
5. 과거 전적과 영수증은 그대로 재생된다.
6. 동일 인물의 서로 다른 시리즈 ID가 테스트에서 합쳐지지 않는다.
7. 원장 비활성화 시 모든 게임의 동일 시드 `resultHash`가 변하지 않는다.

프로필과 초상이 없는 상태에서 `npc-ledger/2.0`을 먼저 배포하지 않는다. 신원 명부는 완성됐지만 경제 이력이 시작되는 순간부터 데이터가 동결되므로, 전환은 첫 완성 배치와 함께 한다.
