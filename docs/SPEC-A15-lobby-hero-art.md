# SPEC-A15 — 로비 캐비닛 히어로 이미지

> 상태: v1.0 구현 계약 (2026-07-25). 선행 없음. 다른 명세와 병렬로 진행할 수 있다.

## 1. 목적

로비의 캐비닛 카드가 아이콘과 텍스트뿐이다. 각 캐비닛이 **어떤 세계의 게임인지** 한눈에 보이지 않는다.

카드마다 그 세계의 이미지를 꽉 채운다. 봇카드 인물이 게임에 실제로 들어간다는 제품 명제가
**로비 첫 화면에서** 전달되어야 한다.

## 2. 설계 결정과 근거

| 결정 | 근거 |
|---|---|
| 레지스트리에 `heroImage`를 선언한다 | 앱 셸에 캐비닛별 분기를 만들지 않는다는 기존 원칙 그대로다 |
| 전용 로비 아트를 굽는다 | 초상은 3:4, 로비 카드는 가로형이다. CSS로 자르면 인물 얼굴이 잘린다 |
| 개인 카드는 런타임 초상을 쓴다 | 빌드 타임에 알 수 없다. 이미 에셋 워커가 뽑고 있다 |
| 이미지가 없으면 지금 레이아웃으로 떨어진다 | 새 세계·새 카드에서 빈 칸이 생기면 안 된다 |

## 3. 무엇을 쓰는가

| 캐비닛 | 소재 |
|---|---|
| 테메로세 도둑잡기 | `pequod-ruins` 배경 + 좌석 인물 초상 합성 |
| 테메로세: 여백 | `pequod-ruins` 또는 니은 초상 |
| 소녀전선 최애 월드컵 | GFL 인물 초상 3~4인 합성 |
| 작전 암호 기억 · 잔불 작전 | 같은 팩의 인물 |
| 인디언 포커 | 테메로세 좌석 인물 + 카드 |
| **내 카드 도둑잡기 · 최애 월드컵(카드)** | **그 카드의 대표 초상** — 런타임 |

## 5. 금지사항

1. **초기 JS 예산을 늘리지 않는다.** 이미지는 JS가 아니지만 청크에 인라인하지 않는다.
2. **원본 대형 에셋을 그대로 쓰지 않는다.** 로비 전용 파생본만 쓴다.
3. **텍스트 대비를 잃지 않는다.** 제목·설명이 이미지 위에서 읽혀야 한다.
4. **이미지 실패가 카드를 깨뜨리지 않는다.** 폴백이 기본 동작이다.
5. **개인 카드 초상을 서버로 보내거나 캐시에 영구 저장하지 않는다.** 기존 Object URL 규칙을 따른다.
6. **레이아웃 이동(CLS)을 만들지 않는다.** 자리를 미리 잡는다.
7. **금지 에셋 정책을 우회하지 않는다.** 소재는 이미 승인된 허용 목록에서만 고른다.

## 6. 아트 규격

```
비율   16:9
크기   sm 384×216 · md 768×432
형식   WebP, 품질 82
상한   장당 60 KB
```

- 인물이 **좌측 또는 우측 3분의 1**에 오도록 구성한다. 반대편이 텍스트 자리다.
- 어두운 그라디언트를 텍스트 쪽에 굽는다. 런타임 오버레이보다 대비가 안정적이다.
- `content-cli`가 소재 경로·크롭·합성 위치를 선언으로 받아 굽는다. 하드코딩하지 않는다.

## 7. 화면 계약

```
.arcade-entry
  ├─ 히어로 이미지 (16:9, object-fit: cover)
  ├─ 그라디언트 위에 배지 · 제목 · 설명 · 시간/세계
  └─ 시작 버튼
```

- 첫 카드만 `loading="eager"` + `fetchpriority="high"`, 나머지는 `loading="lazy"`.
- `decoding="async"`를 전부 붙인다.
- `aspect-ratio`로 자리를 미리 잡아 이미지 도착 전후 레이아웃이 움직이지 않게 한다.
- 이미지는 장식이다. `alt=""`로 두고 이름은 제목 텍스트가 전달한다.
- 모바일에서 `sm`, 데스크톱에서 `md`를 `srcset`으로 고른다.
- 개인 카드 캐비닛은 초상이 준비되기 전까지 폴백 레이아웃을 유지한다. 스켈레톤이 깜빡이지 않게 한다.

## 8. 테스트 관문

1. **선언 없는 캐비닛** — `heroImage`가 없으면 기존 아이콘 레이아웃이 그대로 렌더된다.
2. **로드 실패** — 이미지 404에서도 카드가 깨지지 않고 텍스트가 읽힌다.
3. **규격** — 컴파일된 아트가 16:9이고 장당 60 KB 이하다.
4. **금지 에셋** — 허용 목록 밖 소재를 지정하면 컴파일이 실패한다.
5. **지연 로딩** — 첫 카드 외에는 `loading="lazy"`다.
6. **레이아웃 안정** — 이미지 전후로 카드 높이가 변하지 않는다.

E2E

7. 로비에서 공개 캐비닛에 이미지가 보인다.
8. 개인 카드를 넣으면 그 카드 초상이 카드 캐비닛에 보인다.
9. 모바일에서 제목·설명이 이미지 위에서 잘리지 않는다.
