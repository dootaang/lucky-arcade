# A17 사후 화면검수 대기표

2026-07-26 오너 결정에 따라 후보를 먼저 구현하고 실제 화면에서 확인한다. 자동 감사와 선언 용도 승인은 배포 조건이며, 육안 확인은 구현 결과의 크롭·가독성·분위기를 조정하는 후속 관문이다.

| 팩 | 항목 | 현재 상태 | 확인 화면 |
|---|---:|---|---|
| `temerosa-casino-venue/0.1.0` | Venue 히어로 1 | 사후 확인 대기 | 럭키★오락실 로비, 모바일 16:9 |
| `temerosa-casino-slots/0.1.0` | 슬롯 심볼 16 | 사후 확인 대기 | 슬롯 수직 시제품 |
| `temerosa-casino-floor/0.1.0` | 바닥·테이블 배경 4 | 사후 확인 대기 | 카지노 플로어 및 해당 테이블 |

확인 결과는 항목별로 `accepted` 또는 `rejected`로 큐에 기록한다. 거절은 원본 삭제가 아니라 해당 용도의 다음 배포 제외를 뜻하며, 다른 용도로 자동 전파하지 않는다.
