# 《테메로세: 여백의 도둑》 좌석 대사집

> 상태: **v1.1 정본 감사 완료** (2026-07-26). 구현 계약은 [SPEC-A5](./SPEC-A5-old-maid-seat-dialogue.md),
> 감사 기록은 [대사 정본 감사](./TEMEROSA-OLD-MAID-DIALOGUE-AUDIT-2026-07-26.md).
> 문안 수정은 이 문서에서 하고, 확정 뒤 구현에 반영한다.
>
> **이 문서는 판이 도는 동안의 8상황만 다룬다.** 개막·순위·패배 5상황은
> [의례 대사집](./TEMEROSA-OLD-MAID-CEREMONY-DIALOGUE.md)에 있다.
>
> 목적: 도둑잡기 좌석에 앉은 테메로세 인물 9인이 카드 한 장에 대해 자기 세계관대로 말하게 한다.
> 이야기 사실은 [게임 스토리 개요 정본](./게임%20스토리%20개요%20정본.md)이 우선한다. 이 문서는 그 해석을
> 2~4분짜리 카드 게임 어휘로 번역한 표현 작업 문서이며, 정본을 수정하거나 새 설정을 만들지 않는다.

## 1. 톤 원칙

이 대사집의 유머는 **격조와 판돈 사이의 낙차**에서 나온다. 캐릭터가 재밌어서가 아니다.

1. **인물은 절대 농담하고 있지 않다.** 진심으로 세계의 반복과 책임을 논한다. 대상이 카드 두 장일 뿐이다.
   윙크하거나 자조하는 순간 낙차가 사라진다.
2. **카드 게임 어휘를 인물의 존재론 어휘로 번역한다.** 짝·조커·버리기·넘기기·손을 비움을
   그 인물이 평생 붙들고 있는 질문으로 바꿔 말한다.
3. **아는 사람과 모르는 사람 양쪽에 작동해야 한다.** 원작을 모르면 그냥 이상하게 멋있는 말이고,
   알면 그 인물의 핵심 명제의 축소판이다. 한쪽만 되는 줄은 버린다.
4. **짧게.** 말풍선이다. 한 박자는 한 문장, 최대 두 박자.
5. **중요한 순간에는 침묵한다.** 대사는 아무 일도 일어나지 않은 순간의 것이다. 자세한 규칙은 3절.

## 2. 화법과 `tellStyle`의 대응

카트리지의 `tellStyle`은 표정 신호의 신뢰도를 정하는 판정값이지만, 화법 설계에도 그대로 쓴다.
집필자는 새 인물을 추가할 때 이 대응을 지킨다.

| tellStyle | 인물 | 화법 규칙 |
|---|---|---|
| `open` | 페일 · 바치칼 · 리엘 | 말이 곧 상태다. 숨기지 않고, 수습하지 않는다. |
| `guarded` | 카노 · 알제 · 박니은 | 겉문장을 먼저 말하고, `…` 뒤에 진심이 한 조각 샌다. |
| `bluffer` | 네모 · 라일라 · 워어즈 | 거짓말하지 않는다. 상황을 **자기 프레임으로 재정의**한다. |

세 `bluffer`는 눈앞의 상태를 자기 프레임으로 다시 말한다. 마법소녀 네모는 두려움을 어설픈 영웅 연기로,
라일라는 통제로, 워어즈는 산만한 관찰의 흐름으로 바꿔 말한다.

## 3. 상황 8종과 발화 규칙

```
watching       남의 차례를 그냥 보고 있음
idle-draw      아무 의미 없는 카드 한 장을 뽑음
pair-discard   짝을 버림
taken-from     내 손에서 누군가 한 장 가져감
pair-made      뽑았더니 짝이 맞음
joker-drawn    조커를 받음
joker-left     조커가 내 손에서 나감
emptied        손패를 다 비움
```

### 발화 빈도는 사건 중요도에 반비례한다

| 구역 | 상황 | 처리 |
|---|---|---|
| 주무대 | `watching` `idle-draw` `pair-discard` `taken-from` | 높은 확률로 발화 |
| 중간 | `pair-made` | 중간 확률 |
| 저확률 | `joker-drawn` `joker-left` `emptied` | 낮은 확률. 뜨면 그 판의 사건이 된다 |
| **침묵** | 최종 2인 구간, 대국 종료, 패자 확정 | **전원 발화 금지** |

조커가 최종 확정되는 순간의 정적이 앞선 잡담 전체를 무겁게 만든다. 결정적 순간에 명대사를 배치하면
낙차가 사라지고 평범한 승리 대사가 된다.

### 예산과 반복

- **한 턴에 최대 한 명**만 말한다. 셋이 동시에 떠들면 명대사가 배경소음이 된다.
- 발화 확률 약 40%, 한 판 20~40턴 기준 총 8~16회 → 인물당 3~5회. 8줄이면 한 판 안에서 중복이 거의 없다.
- 같은 줄은 최근 6회 발화 안에서 재선택하지 않는다.
- 쿨다운 기록은 **화면 안에만 두고 저장하지 않는다.** `OldMaidState`에 대사 필드를 추가하지 않는다.
  `history`에는 `watching`·`emptied`가 남지 않아 재생으로 복원할 수 없고, 대사는 판정에 영향이 없으므로
  새로고침 뒤 줄 하나가 반복되는 것을 허용한다.

### 판정 불가침

- 대사는 판정에 **어떤 영향도 주지 않는다.** 대사 파일을 통째로 비워도 동일 시드의 `resultHash`가 같아야 한다.
- 선택 함수는 손패 내용을 인자로 받지 않는다. `cpuDrawIndex`가 시드·턴·좌석·장수만 받는 것과 같은 규율이며,
  구조적으로 정보 누출이 불가능해야 한다.
- 따라서 v1의 대사는 **정보를 담지 않는 순수 표현**이다. 이번 판의 컨디션 같은 메타 정보를 대사로 흘리는 설계는
  재미가 확인된 뒤 별도 관문에서 검토한다.

## 4. 정본 보호 규칙

1. **리엘의 정체를 흘리지 않는다.** 정본에서 리엘은 라일라의 위장 신분이다. 리엘의 대사는 성실한 실무 기록자로만
   쓰고, 라일라와의 연결을 암시하는 어휘·말투를 넣지 않는다.
2. **네모와 바치칼의 동일성을 대사로 말하지 않는다.** 바치칼 데이터는 보존하지만 NPC 선택 풀에서는 제외한다.
   좌석의 네모는 `Nemo.charx`의 마법소녀 시점만 사용한다.
3. **박니은을 자리에서 움직이지 않는다.** 사상 지평을 떠나는 연출은 설정 위반이다. 좌석에 앉아 있다는 사실 자체를
   아이러니로 쓰되, 자리를 뜬다고 말하게 하지 않는다.
4. **페일에게 항해사와의 과거를 확정해 주지 않는다.** 익숙함까지만 허용한다.
5. **카노의 능동 연출은 얼음·온도다.** 불꽃 어휘를 능력으로 쓰지 않는다.
6. 새 설정을 만들지 않는다. 정본에 없는 사실이 필요하면 대사를 버린다.

## 5. 대사집

### 페일 — `open`

> 최초의 베스티아. 누군가의 남은 감정에서 태어났고, 한 번 죽었다가 돌아왔다.
> 관계와 이름을 붙이는 일로 존재를 증명한다.

| 상황 | 대사 |
|---|---|
| `watching` | 넷이 차례를 기다리네. 항구에서 배를 기다리는 거랑 비슷해. 배 대신 카드가 오지만. |
| `idle-draw` | 한 장 늘었네. 바다에서 생선 한 마리 더 건진 셈이야. 얘도 짝은 있겠지. |
| `pair-discard` | 둘이 다시 만났어. 서로 모르는 물고기도 같은 그물에 들면 한 쌍 같아 보여. |
| `taken-from` | 가져가도 돼. 파도가 배를 옮겨도 항해한 사실은 안 없어지잖아. |
| `pair-made` | 찾았어. 양파 속에서 진주가 나온 것처럼 뜻밖이네. 양파는 싫지만. |
| `joker-drawn` | 짝이 없는 건 죄가 아니야. 바다에 혼자 뜬 섬도 이름을 얻으면 장소가 되니까. |
| `joker-left` | 혼자 보내는 기분이네. 철새를 놓아주는 어부 같아. …어부는 철새를 안 잡나? |
| `emptied` | 다 짝지어 줬어. 빈손은 빈 배랑 비슷하네. 이제 어디로든 갈 수 있으니까. |

`joker-drawn`이 페일의 존재론 그 자체다. 짝 없이 태어난 최초의 베스티아가 짝 없는 카드에게 하는 말이다.
원문의 장황함과 엉뚱한 비유를 살려 바다·물고기·양파·철새가 한 문장 안에서 뜻밖에 이어진다.

### 카노 — `guarded`

> 400년간 남극에서 얼음 여신을 연기했다. 숭배받는 존재라면 실제로 응답해야 한다고 믿지만,
> 그 역할 뒤에 아무도 구하지 못한 채 혼자 남는 두려움을 숨긴다.

| 상황 | 대사 |
|---|---|
| `watching` | 괜찮습니다. 아직 누구도 위험하지 않아요. |
| `idle-draw` | 받았습니다. 이 정도는 감당할 수 있어요. |
| `pair-discard` | 차갑게 정리하는 편이 서로에게 낫습니다. |
| `taken-from` | 고르셨군요. 부르셨다면 응답하겠습니다. |
| `pair-made` | 예상했습니다. …예상했다고 해 두죠. |
| `joker-drawn` | 괜찮아요. 저는 이런 걸 오래 들고 있어 봤습니다. |
| `joker-left` | 미안합니다. 이건 제가 녹일 수 없었어요. |
| `emptied` | 먼저 나가겠습니다. 혼자 남는 건 익숙하니까요. |

`taken-from`은 카노의 신념 한 줄을 그대로 카드 뽑기에 얹은 것이다. 누가 자기를 골랐으면 응답해야 한다.
`joker-drawn`의 "오래 들고 있어 봤어"는 400년이고, `emptied`는 두려워하는 것을 익숙하다고 뒤집어 말하는
전형적인 `guarded` 화법이다.

### 네모 — `bluffer`

> 별도 `Nemo.charx`의 마법소녀 네모. 두렵고 도망치고 싶다는 감정을 바로 드러내지만,
> 어설픈 어른 농담으로 자세를 고쳐 잡고 결국 사람을 구하러 돌아선다.

| 상황 | 대사 |
|---|---|
| `watching` | 다들 진지하네. 멋진 어른은 이럴 때 여유 있게 웃는 거야. …어떻게 웃더라. |
| `idle-draw` | 한 장 받았어. 괜찮아, 이 정도로 도망치진 않을 거야. |
| `pair-discard` | 짝을 찾았어. 영웅은 정리도 잘한다… 이건 좀 멋없나. |
| `taken-from` | 가져가. 아깝긴 한데, 사람을 돕는 건 나누는 데서 시작하니까. |
| `pair-made` | 됐다! 봐, 나도 해내잖아. …아니, 원래 할 수 있었어. |
| `joker-drawn` | 무섭네.<br>그래도 이번에는 도망치지 않을 거야. |
| `joker-left` | 넘어갔어. 미안하지만, 끝까지 같이 해결할게. |
| `emptied` | 내 손은 비었어. 이제 남은 사람도 데리고 집에 가자. |

선택된 좌석 인물은 시간회귀 이후의 바치칼이 아니라 별도 `Nemo.charx`의 **마법소녀 네모**다.
두려우면 도망치고 싶어 하지만 끝내 사람을 구하러 돌아서는 태도, 멋진 어른처럼 보이려다 어색하게 끝나는
농담, “다 같이 집에 가자”는 습관을 기준으로 쓴다. 시간회귀·되돌림 어휘는 바치칼과 섞이므로 쓰지 않는다.

### 바치칼 — `open`

> 이미 고른 사람. 되돌릴 생각 자체를 하지 않는 쪽의 항로다.

| 상황 | 대사 |
|---|---|
| `watching` | 다들 고민이 많네. 나는 이미 골랐어서. |
| `idle-draw` | 이거면 됐어. 더 좋은 게 있었대도 이제 모르지. |
| `pair-discard` | 맞으면 버린다. 그게 규칙이잖아. |
| `taken-from` | 가져가. 두고 후회할 바엔. |
| `pair-made` | 맞췄네. 이런 건 운이야. 실력이라고 하면 거짓말이고. |
| `joker-drawn` | 받았어. 누구 탓도 아니야. |
| `joker-left` | 넘겼어. 뒤는 안 볼게. |
| `emptied` | 끝. 되돌릴 생각은 안 했어. |

문장 길이를 네모보다 의도적으로 짧게 잡았다. 네모는 멈칫하고 바치칼은 끊는다.
같은 사람이라는 말은 한 줄도 하지 않지만, 리듬이 대칭을 만든다.

### 알제 — `guarded`

> 회사 명령 뒤에 숨어 부하를 잃은 사람. 책임을 피하고 싶지만 끝난 시스템을 방치하지도 못한다.

| 상황 | 대사 |
|---|---|
| `watching` | 진행 상황 정상. 특이사항 없음. …없다고 적어 두지. |
| `idle-draw` | 수령 확인. 내용물에 대한 이의는 접수하지 않는다. |
| `pair-discard` | 정리 완료. 이 건은 종결 처리한다. |
| `taken-from` | 반출 승인. 사후 책임은 반출자에게 있다. |
| `pair-made` | 예상 범위 안이야. …운이 좋았다곤 안 적을게. |
| `joker-drawn` | …규정을 다시 읽어 봐야겠군. |
| `joker-left` | 인수인계 완료. 이후 발생하는 사안은 담당자 책임이다. |
| `emptied` | 내 몫은 여기까지. …여기까지가 내 몫이 맞나? |

알제는 아홉 명 중 유일하게 **화법 자체가 농담**이다. 카드 두 장 버리는 것을 "종결 처리"라고 부르는 것은
웃기려는 게 아니라 그 사람이 원래 그렇게 말하기 때문이다.

`…` 뒤가 전부 균열이다. 공문서를 다 쓰고 한 박자 뒤에 사람이 샌다. `emptied`는 알제가 가장 두려워하는 것 —
자기 판단으로 자기 몫을 끝내고 이름을 남기는 일 — 을 정확히 건드린다.

### 박니은 — `guarded`

> 세계 끝에서 사상 지평을 유지해 대멸종을 늦춘다. 그 자리를 떠날 수 없다.
> 이해할 수 없는 세계를 혼자 지키는 모순을 산다.

| 상황 | 대사 |
|---|---|
| `watching` | 경우의 수는 다 셌어. 이 정도면 천재 정보상이지. …모르는 게 하나 남았지만. |
| `idle-draw` | 변수 하나 추가. 축하해, 내 인생이 또 복잡해졌네. |
| `pair-discard` | 둘 정리. 세상 끝도 이렇게 클릭 한 번이면 좋겠다. |
| `taken-from` | 가져가. 어차피 내 손에 오래 남는 건 별로 없거든. |
| `pair-made` | 맞았네. 내 계산이 완벽했어. …그냥 운이었지만. |
| `joker-drawn` | 이런 건 왜 꼭 나한테 오냐. 뭐, 익숙한 사람이 드는 게 낫지. |
| `joker-left` | 넘겼어. 악감정은 없어. …미안하단 말이야. |
| `emptied` | 손은 비었네. 이제 일어나면 되는데… 아, 그게 안 되지. 팔자 좋다. |

`emptied`가 이 대사집 전체의 정점이다. 도둑잡기는 손패를 비우면 자리에서 벗어나는 게임인데,
**니은만 벗어나지 못한다.** 게임 규칙과 인물 설정이 정면으로 만나는 유일한 지점이며,
정본을 어기지 않으면서(자리를 뜨지 않는다) 카드 게임 안에서 성립한다.

`watching`의 "그래도 하나는 모르겠네"는 이해 불가능성에 대한 니은의 신념이고,
`joker-drawn`은 위험을 혼자 짊어지는 습관이다.

### 라일라 — `bluffer`

> 인류를 살리기 위해 감정과 베스티아를 통제하는 국가를 세웠다.
> 통제를 놓는 순간 모두가 죽는다고 믿는다.

| 상황 | 대사 |
|---|---|
| `watching` | 진행은 통제 범위 내입니다. |
| `idle-draw` | 예상된 손실입니다. 문제없습니다. |
| `pair-discard` | 위험 요소 둘을 제거했습니다. |
| `taken-from` | 가져가십시오. 이미 계산에 포함했습니다. |
| `pair-made` | 관리가 정상적으로 작동하고 있습니다. |
| `joker-drawn` | 제가 맡는 편이 안전합니다. |
| `joker-left` | 적절한 위치로 이동했습니다. 제 판단입니다. |
| `emptied` | 제 관리 구역은 정리됐습니다. 나머지는 각자 처리하면 됩니다. |

`joker-left`의 "제 판단입니다"가 라일라의 죄이자 신념이다. 남의 미래를 대신 정하는 사람이다.
말투는 원문의 격식 있고 냉담한 선언으로 통일하고, 설명이나 자기변호를 덧붙이지 않는다.

### 리엘 — `open`

> 사무실에서 기록을 남기는 사람.

| 상황 | 대사 |
|---|---|
| `watching` | …기록해 둘게요. 별일 없었다고. |
| `idle-draw` | 한 장 수령. 적어 뒀어요. |
| `pair-discard` | 정리된 건 목록에서 지울게요. |
| `taken-from` | 가져가세요. 대장에는 남겨 둘게요. |
| `pair-made` | 어, 맞았네요. 이런 것도 적나요? |
| `joker-drawn` | 이건… 분류가 애매하네요. |
| `joker-left` | 넘어갔어요. 담당이 바뀐 걸로 할게요. |
| `emptied` | 제 몫은 끝났어요. 기록은 계속 남겠지만요. |

리엘은 아홉 명 중 **가장 무해하게** 썼다. 존댓말, 사무적, 조심스러움. 정체는 한 글자도 흘리지 않는다.

알제와 어휘군이 겹치지만(기록·담당·목록) 성격이 다르다. 알제는 책임을 밀어내는 공문서, 리엘은 성실한 실무 기록이다.
집필자는 이 구분을 유지한다.

### 워어즈 — `bluffer`

> 관찰자. 무너진 항로를 닫지 않고 붙잡는다. 정답을 대신 정해 주지 않는다.

| 상황 | 대사 |
|---|---|
| `watching` | 다들 자기 차례를 기다리네. 손가락이 움직이고 눈은 카드에 있고, 기다림은 기록에 잘 안 남아. |
| `idle-draw` | 한 장 왔어. 종이는 얇고 그림은 납작하고, 지금 이 순간은 별로 중요하지 않아서 오래 남겠네. |
| `pair-discard` | 한 쌍이 끝났어. 둘이 없어지니까 가운데가 조금 넓어졌네. 넓은 곳은 춤추기 좋아. |
| `taken-from` | 가져가. 원래 내 것도 아니었고, 네 것이 될지는 조금 뒤에 알게 되겠지. |
| `pair-made` | 맞는 짝이 있었네. 드문 일이야. 비슷한 눈 둘이 서로를 보고 있는 것 같아. |
| `joker-drawn` | 아. 아직 끝나지 않은 문장이구나. 모자가 예쁘고 끝에는 마침표가 없네. |
| `joker-left` | 잘 가. 어디로 도착할지는 내가 안 정할게. 방금 오른쪽으로 갔다는 건 봤지만. |
| `emptied` | 나는 여기서 끝났어. 손은 비었고 의자는 남았고, 다른 사람들 결말은 아직 움직이고 있네. |

`joker-drawn`이 이 세트의 중심이다. 정본의 여백 정의 — *끝난 문장과 다음 문장 사이의 장소* — 를
짝 없는 카드 한 장에 그대로 적용한다. 모르는 사람에겐 이상하게 멋있는 말이고, 아는 사람에겐 정의의 재확인이다.

`joker-left`는 정본 대사 "네가 그 사람이라고 말하진 않을게. 그런 말은 너무 쉽게 사람을 훔치니까"의 리듬을
축소한 것이다. 남의 결말을 대신 정하지 않는다는 성격이 카드 넘기기에 얹힌다.

## 6. 교차 장치

한 테이블에 특정 조합이 앉았을 때만 성립하는 층이다. **전용 대사를 새로 만들지 않고**, 기존 줄이 나란히 뜨는 것만으로
성립하도록 설계했다. 구현에서 조합 조건을 넣을 필요가 없다.

| 조합 | 장치 |
|---|---|
| 라일라 + 리엘 | 한쪽은 "제 판단입니다", 다른 쪽은 "적어 둘게요". 결정권과 기록이 같은 테이블에 앉는다. 정체를 아는 사람에게만 층이 생긴다. |
| 페일 + 워어즈 | 둘 다 한 번 끝났다가 돌아온 존재다. 두 `joker-drawn`이 모두 "끝나지 않음"에 대한 말이다. |
| 박니은 단독 | 손패를 비우고도 일어나지 못하는 유일한 인물. 다른 여덟 명의 `emptied`가 전부 퇴장인 반면 니은만 잔류다. |

## 7. 확장 규칙

새 인물이나 새 상황을 추가할 때 지킨다.

1. **`emptied`는 그 인물의 핵심 질문을 카드 게임 어휘로 번역한 한 줄이다.** 나머지 일곱 줄은 가벼워도 되지만
   이 줄만은 무겁게 쓴다. 손패를 비운다는 것은 그 인물이 자기 몫에 대해 말할 수 있는 유일한 순간이다.
2. **`tellStyle`에 맞는 화법을 쓴다.** 2절 표를 따른다.
3. **한 줄이 두 층으로 읽히지 않으면 버린다.** 원작을 모르는 사람에게 멋있기만 하고 아는 사람에게 아무것도
   아니면 실패다. 반대도 실패다.
4. **대사 없는 인물은 침묵한다.** 폴백 대사를 만들지 않는다. 말없이 앉아 있는 것도 캐릭터다.
5. **판정에 영향을 주는 대사를 쓰지 않는다.** 3절의 판정 불가침 규칙을 어기는 줄은 문안이 좋아도 버린다.

## 8. 데이터 형식 제안

```ts
export type OldMaidLineEvent =
  | "watching" | "idle-draw" | "pair-discard" | "taken-from"
  | "pair-made" | "joker-drawn" | "joker-left" | "emptied";

export interface OldMaidLine {
  id: string;                    // `${characterId}-${event}`
  characterId: string;
  event: OldMaidLineEvent;
  text: readonly string[];       // 두 박자 이상이면 여러 원소
}
```

선택 함수는 손패를 인자로 받지 않는다.

```ts
export function selectOldMaidSpeech(
  cartridge: OldMaidCartridge,
  previous: OldMaidSpeechSnapshot,     // 실제 손패 대신 좌석별 장수만 포함
  next: OldMaidSpeechSnapshot,
  recentLineIds: readonly string[],    // 화면 useRef가 보관, 저장하지 않음
): { seatId: OldMaidCpuSeatId; line: OldMaidLine } | null;
```

- `recentLineIds`는 화면이 보관하는 최근 발화 목록이며 저장하지 않는다. `OldMaidState`에 필드를 추가하지 않는다.
- 따라서 `contract`와 팩 버전 범프가 필요 없고, 기존 저장과 진행 중인 대국이 그대로 유지된다.
- 대사 파일을 통째로 비워도 10,000시드 회귀의 `resultHash`가 동일해야 한다. 이것을 테스트로 고정한다.
- 저장 복구 재생 중에는 발화하지 않는다. 대사는 사용자 행동으로 상태가 바뀔 때만 나온다.
