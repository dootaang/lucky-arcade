# 테메로세 카지노 제안 비교 검토

> 목적: 2026-07-25 논의에서 나온 Venue·경제·게임·에셋 제안을 현재 코드와 제품 원칙에 대조해,
> 채택·수정·보류 결정을 한곳에 고정한다.

## 종합 판정

`럭키★오락실 → 테메로세 카지노 → 각 테이블`의 2단 구조는 채택한다. 럭키★오락실은 여러 봇 IP를
받는 중립 플랫폼으로 남고, 테메로세 카지노는 현재 유일한 공개 Venue가 된다. 이 구조는 선택과 집중과
장래 확장성을 동시에 만족한다.

슬롯·관전 예측·인디언 포커·더비는 테메로세의 인물 표정, 유물, 괴물, 배경을 실제 규칙과 연출에 쓰므로
일반 카드게임보다 제품 차별화가 크다. 반면 하이로우·블랙잭·홀덤은 익숙하지만 테메로세 자산을 장식으로만
쓸 위험이 있어 뒤로 둔다.

## 게임 포트폴리오 재정렬

우선순위는 카지노에서 흔한가보다 **테메로세 자산이 규칙에 얼마나 깊게 들어가는가**, **공용 기반을 실제로
검증하는가**, **한 판이 완결되는가**로 정한다.

1. **무료 도둑잡기** — 이미 완성된 포인트 발행원이며 카지노의 입문 테이블이다.
2. **슬롯 777 수직 시제품** — 승인된 정사각 유물 심볼로 Venue와 수집 경제를 가장 빨리 증명한다.
3. **인디언 포커 개정** — 표정 읽기와 라운드 베팅을 결합해 테메로세 카지노의 핵심 차별점을 증명한다.
4. **NPC 관전 예측** — 기존 관전 기록 위에 별도 예측 코어를 얹는다.
5. **더비 중계** — Phaser 단일 표현과 배당을 검증한 뒤 베이크오프 화면을 제품 화면으로 교체한다.
6. **빙고** — 승인된 얼굴·유물 풀의 재사용 폭을 검증한다.
7. **하이로우·블랙잭** — 작고 익숙하지만 IP 결합이 얕으므로 위 실험 뒤에 둔다.
8. **피쉬 헌팅·플링코·파친코** — 고정 스텝 입력 재생과 물리 표현 분리 수직 시제품 뒤에만 연다.
9. **다우트·원카드·홀덤** — 공용화할 두 번째 실제 소비자가 생길 때 필요한 규칙만 추출한다.

스크래치는 독립 캐비닛보다 뽑기·보너스 개봉 연출로 먼저 검증한다. 휠은 테메로세 자산이 결과 라벨에만
붙는다면 보류한다. 섯다는 화투 에셋의 출처·사용 허가·감사가 끝날 때까지 시작하지 않는다.

## 조사와 수치의 신뢰도

카지노 장르 탐색에 사용된 위키·개발사 마케팅 글은 아이디어 발산에는 충분하지만 구현 계약의 근거로는 약하다.
명세에는 이 글들의 장르 설명을 권위 근거로 인용하지 않는다. 실제 규칙, 배당, 접근성, 엔진 능력은 공식 규칙서,
엔진 소스, 제조사 문서 또는 직접 만든 결정론 테스트로 확인한다.

원본 카드 5개·약 265MB, 이미지 1,826개라는 수치는 작업 재고의 출발점이다. 그중 `234 제외 / 1,592 안전`,
`473 괴물 / 89 슬롯 심볼 / 122 배경`은 확정 재고가 아니다. 현재 확정 가능한 표현은 다음뿐이다.

- 234개: 이름 기반 제외 후보.
- 1,592개: 이름 필터를 통과한 미검수 후보.
- 473/314/89/122개: 해상도·종횡비로 나눈 작업 큐.
- 503개 고유 이름: 파일명 기준 수치이며 바이트·지각 중복 제거 결과가 아니다.

최종 배포 수치는 [SPEC-A17](./SPEC-A17-temerosa-casino-asset-inventory.md)의 감사 산출물만 정본으로 삼는다.
