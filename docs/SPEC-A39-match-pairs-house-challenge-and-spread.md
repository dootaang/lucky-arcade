# SPEC-A39 — 짝맞추기 하우스 도전과 성과 스프레드

> 상태: `match-pairs/0.5` 구현 계약 (2026-08-02).
> 기존 고정 승패 배당을 폐기하고 무료 수입원과 감사 가능한 직접 베팅을 분리한다.

## 1. 입장 방식

| 방식 | 입장 | 상대 | 정산 |
|---|---:|---|---|
| 연습 대국 | 무료 | 직접 선택 | 없음 |
| 하우스 도전 | 무료 | 입장 가능한 30인 중 시작 시 결정론 무작위 배정 | 완주 1~8 P |
| 포인트 매치 | 10/50/200 P × 2~5배 | 직접 선택 | 최대 손익이 같은 대칭 정산 |
| NPC 대 NPC 관전 | 무료 | 두 NPC 선택 | 없음. 베팅은 통합 관전 시장에서만 받음 |

하우스 도전은 테메로세 카지노에서 도둑잡기와 함께 무자본으로 포인트를 얻는 통로다. 연습은 결과를
경제에 연결하지 않는다. 관전 화면 안에 별도 베팅을 다시 만들지 않는다.

## 2. 하우스 도전 보상

완료된 공개 결과만 사용한다.

```text
결과 보상: 승 5 / 무 2 / 패 1
효율 보상: 기준 시도 초과 0~2회 +3, 3~4회 +2, 5~6회 +1, 그 이상 +0
최종 보상: min(8, 결과 보상 + 효율 보상)
```

지급 키는 세션과 완료 시퀀스로 고정한다. 같은 완료 화면을 새로고침해도 한 번만 지급한다. 지급은 로컬
플레이어 지갑과 하우스 무료게임 비용을 한 거래로 기록한다.

## 3. 성과 스프레드

승패에 돈을 걸지 않는다. 완료 시 다음 점수를 계산한다.

```text
성과 점수 = (플레이어가 찾은 짝 − NPC가 찾은 짝) × 10
          − max(0, 전체 시도 − 난도별 전체 짝 수)
```

플레이어 점수가 동결된 기준점을 **초과**하면 적중이다. 같은 점수는 미달이다. 대국 승리와 베팅 적중은
서로 다른 결과이며 결과 화면과 전적에 둘 다 남긴다.

노출액은 `판돈 × 배율`이다. 시작 전에 플레이어와 하우스가 같은 노출액을 예약한다. 적중하면 플레이어가
양쪽 예약액을 받고, 미달이면 하우스가 양쪽 예약액을 받는다. 따라서 5배를 딸 수 있으면 5배를 잃는다.

## 4. 가격 감사

- 가격 버전: `temerosa-match-pairs-spread/0.1`
- 조건: 30 NPC × 쉬움/보통 × 느긋함/보통/날카로움 = 180개
- 정책: 숨은 카드를 읽지 않고 공개된 카드만 완전히 기억하는 플레이어
- 표본: 조건당 600 결정론 시드
- 개장 관문: 추정 적중률 30.00~49.00%
- 결과: 142개 개장, 38개 잠금

잠긴 조건은 임의 기준점으로 보간하지 않는다. UI에 `가격 준비 중`으로 표시하고 시작을 막는다. 가격표는
생성 스크립트의 산출물이며 런타임에서 재계산하지 않는다.

## 5. 복구와 금지선

1. 영수증은 카드가 배분되기 전에 시드·NPC·난도·집중도·기준점·가격 버전·최대 노출을 고정한다.
2. 새로고침은 예약 영수증으로 같은 판을 복원한다.
3. 새 계약에서 이탈은 환불 사유가 아니다. 판 결과로 정산해야 한다.
4. 손상·변조·가격 버전 불일치는 시스템 무효화한다.
5. 재생 불가능한 0.4 고정 배당 예약은 전환 시 한 번 전액 환불한다.
6. 타이밍·애니메이션은 `resultHash`에 들어가지 않는다.
7. NPC 기억 코어는 숨은 카드·얼굴 id를 입력받지 않는다.

## 6. 완료 관문

- 180개 가격 키가 중복 없이 존재하고 인물마다 6개 조건을 가진다.
- 개장 가격의 감사 적중률이 49%를 넘지 않는다.
- 보상은 1~8 P이며 완료 시퀀스당 한 번만 지급한다.
- 플레이어와 하우스의 예약액과 최종 손익이 대칭이다.
- 예약 복구 후 동일 시드와 입력은 동일 `resultHash`를 낸다.
- 직접 관전은 무료이며 통합 관전 시장과 중복 베팅하지 않는다.
