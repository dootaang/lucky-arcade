# SPEC-A26 개정 — 실제 다중 경기 NPC 원장 0.5

> 상태: 구현 계약 (2026-07-28). `npc-ledger/0.4`를 대체한다.
> 보존된 이전 계약이다. 현재 계약은 [NPC 원장 0.6](./SPEC-A26-NPC-LEDGER-0.6.md)이다.

## 목적

NPC의 긴 카지노 체류를 정산 한 건으로 취급하지 않는다. 45~120분의 방문 안에서 실제 게임이 여러 번 열리고, 각 경기 결과가 다음 판의 잔고·판돈·레버리지 판단에 반영된다.

## 가짜 중간 정산과의 차이

- 가짜 중간 정산은 방문의 최종 손익을 먼저 정한 뒤 그 숫자에 맞도록 서로 상쇄되는 승패를 끼워 넣는다. 중간 행을 지워도 방문 종가가 정해져 있다.
- 0.5의 실제 경기는 각자 `matchId`, 참가자, 판돈, 배율, 시작·종료 시각과 게임 판정을 가진다. 방문 손익은 그 경기들의 합일 뿐이다. 경기 하나를 지우면 방문 종가도 바뀐다.
- PvP 한 경기는 참가자 전원이 같은 `matchId`를 공유하며, 짝맞추기와 인디언 포커는 정확히 제로섬이다.

## 시간 구조

```
NPC 방문(visitId, 45~120분)
  ├─ 경기 1(matchId) → 실제 정산
  ├─ 경기 2(matchId) → 실제 정산
  ├─ 경기 3(matchId) → 실제 정산
  └─ ...
```

- 슬롯: 45~90초
- 인디언 포커: 2~4분
- 짝맞추기: 3~6분
- 도둑잡기: 4~8분
- 경기 사이 준비 간격: 8~24초
- UTC 시각과 계약 버전으로 전부 재생하며 서버 프로세스는 없다.

## 경제와 성격

- 성격은 승패를 직접 지정하지 않는다. 테이블 선호, 판돈, 2~5배 레버리지, 연승 압박, 손실 추격, 휴식 확률에만 작용한다.
- 승패는 게임별 실력 축과 독립 시드로 판정한다.
- 손절·익절선은 일일 최초 잔고가 아니라 방문 시작 잔고를 기준으로 한다. 임계 도달 시 성격의 discipline에 따라 일부 라운드를 쉬며, 잔고가 20 P 미만이면 유료 경기를 중단한다.
- 슬롯은 플레이어와 같은 3×3·5라인·6심볼 배당표를 쓴다.
- 도둑잡기는 무료 수익원이며 1/2/3/4위에 10/5/3/1 P를 지급한다.

## 표시 계약

- 최근 정산은 NPC별 원장 행이 아니라 경기별로 묶는다. PvP는 한 행에서 승자와 패자의 손익을 함께 보여준다.
- 라이브 플레이 테이프의 모든 행동은 실제 `matchId`를 가진다. 실제 경기와 연결되지 않은 분위기용 가짜 행동은 만들지 않는다.
- 명예의 전당 잔고는 완료된 경기 정산만 반영한다.
- 체크포인트 키는 `npc-ledger/0.5:checkpoint:<dayIndex>`이며 0.4 캐시는 진실로 사용하지 않는다.

## 불변식

1. 동일 입력은 동일 방문·경기·정산을 만든다.
2. PvP 참가자의 경기 손익 합은 0이다.
3. 방문 손익은 그 방문에 속한 경기 손익의 합이다.
4. 모든 접두 시점에서 잔고는 음수가 아니다.
5. 라이브 행동의 `matchId`는 같은 날 실제 경기 목록에 존재한다.
6. 원장을 제거해도 각 게임의 `resultHash`는 바뀌지 않는다.
7. 장기 감사에서는 35명 전원의 10,000일 시퀀스를 안전 정수 범위에서 확인한다.

## 공개 밀도 기준

프로필의 활동 등급 차이는 유지하되 방문 수를 저·중·고 활동군 6~9 / 8~12 / 10~14회로 둔다. 실제 시각 표본에서 최근 정산과 라이브 행동이 모두 0인 장시간 공백이 생기면 실패다. 활동량을 늘리기 위해 NPC 수를 복제하지 않는다.
