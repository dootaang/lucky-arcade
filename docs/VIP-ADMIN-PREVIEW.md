# VIP 블랙잭 관리자 시험 입장

## 사용법

카지노 플로어 → 위층 VIP 룸 → **관리자 시험 입장** → 기존 관리자 비밀번호.
직접 경로는 `/preview/temerosa-vip-blackjack`이다.

- 완주 20판과 회원권 구매 조건 없이 시험 포인트 10,000 P로 시작한다.
- 실제 VIP와 같은 게임 규칙, 화면, 박니은 이미지·대사를 사용한다.
- 관리자 시험 도구에서 초기화, 첫 입장 연출 재생, 이미지 29장 선택, 대사 45개 선택, 컴프 1~4단계 연출을 확인한다.
- 이미지·대사 확인 중에는 게임 조작을 잠근다. `연출 확인 종료 · 게임으로`를 누르면 진행 중이던 패로 돌아간다.
- 이미지는 선택한 항목만 로딩하며 현재 이미지와 전환 대상 두 장까지만 화면에 유지한다.

## 데이터 분리

`vip-table-session.ts`가 화면과 저장 처리의 경계다.

- 실제 플레이: `vip-live-session.ts`만 실제 지갑·회원권·전적·하우스·진행 복구를 사용한다.
- 시험 플레이: `vip-preview-session.ts`만 사용한다. `sessionStorage`의 `lucky-arcade:vip-blackjack-preview:0.1` 한 항목에 시험 잔고·대국·컴프·첫 입장 여부를 저장한다.
- 시험판은 새로고침 후 복구하며 정산은 멱등이다. 손상된 시험 데이터는 오류로 표시하고 명시적 시험 초기화로만 교체한다.
- 시험 초기화는 시험 키만 덮어쓴다. 실제 IndexedDB, localStorage, 경제 워커를 사용하지 않는다.
- 컴프 연출 미리보기는 실제/시험 컴프 누적액과 보상 수령 상태를 바꾸지 않는다.
- 일반 `/play/temerosa-vip-blackjack`은 계속 회원권을 요구한다. 시험 세션으로 정식 입장이 해금되지 않는다.

기존 관리자 비밀번호는 정적 클라이언트의 실수 진입 방지 장치이지 서버 인증이 아니다. 향후 시험 도구를 추가할 때도 실제 저장소 접근을 허용해서는 안 된다.

## 확인한 범위

- 시험 어댑터: 예약·복구·중복 정산·컴프·초기화·손상/충돌·의존 경계.
- 데스크톱/모바일: 비밀번호 문, 정상 VIP 차단 유지, 시험 대국/새로고침/정산, 연출 도구, 이미지 지연 로딩.
- 시험 전후 실제 IndexedDB 전 저장소 내용이 동일하고 시험 중 경제 워커 생성이 0임을 검사한다.
- 실제 VIP 회원권 구매·대국 복구·정산 E2E도 함께 유지한다.

대상 테스트: `vip-preview-session.test.ts`, `e2e/vip-preview.spec.ts`, `e2e/vip-blackjack.spec.ts`.
